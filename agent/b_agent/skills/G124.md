Enforce a Clean Output Format Without Excessive Repetition

**When to apply**: When you need a specific code structure (e.g., a single function with a docstring) in the output, but past instructions have led to extra commentary or multiple code blocks.
**What to do**: State the desired output format clearly once, at the end of the prompt. Use definitive language. Avoid repeating it, as that can confuse the model or use up valuable context tokens.
**Example**: "Complete the following function. Ensure your final output is exactly the `def` statement for the function, its docstring, and its body, with no other text.\n\n# Problem: ..."
**Why it works**: Repetitive formatting instructions can be interpreted as uncertainty, weakening their effect. A single, clear, terminal instruction acts as a strong "post-processing" rule, guiding the model to format its final answer correctly without compromising the generation of the code logic itself.
