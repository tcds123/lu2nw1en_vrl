Structure Prompts with Clear, Imperative Instructions

**When to apply**: For every prompt. This is about overall prompt hygiene to reduce ambiguity and increase instruction-following.

**What to do**: Use direct command verbs ("Write," "Return," "Calculate," "Raise"). Structure requirements as a bulleted or numbered list. Avoid conversational fluff, hedging phrases ("might want to," "could consider"), and contradictory advice. Be concise and sequential.

**Example**: "Write a Python function to calculate factorial. 1. Handle `n=0` correctly. 2. Raise a `ValueError` for `n < 0`. 3. Use an iterative loop, not recursion. 4. Return the integer result."

**Why it works**: Ambiguous, verbose, or conversational prompts lead to inconsistent and verbose model outputs. Contradictions (e.g., "make it fast, but use this slow method") cause confusion and erratic code. Imperative lists provide a clear, stepwise checklist for the model to follow, improving reliability and adherence to requirements.
