Maintain Coherent, Concise Instructions to Reduce Noise

**When to apply**: For all prompt construction. Especially critical when combining multiple constraints or when the problem statement itself is complex.
**What to do**: Write instructions in clear, imperative sentences. Group related requirements. Avoid meta-commentary ("This is important because..."), rhetorical questions, or repeating the same requirement in different words. Use bullet points for discrete requirements.
**Example**: "Implement a function to serialize and deserialize a binary tree.
- Use preorder traversal with 'X' for null nodes.
- Serialize to a single string.
- Deserialize the string back to the original tree structure.
The function signatures are `def serialize(root: TreeNode) -> str:` and `def deserialize(data: str) -> TreeNode:`."
**Why it works**: Verbose, meandering prompts can confuse the model, causing it to miss key details or prioritize minor points. Concise, structured prompts improve the model's comprehension and adherence to the primary task.
