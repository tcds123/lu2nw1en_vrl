Mandate Use of Specific, Optimal Built-in Libraries

**When to apply**: When a task has a known idiomatic solution using a specific standard library (e.g., `collections.Counter` for frequency, `str.maketrans` for character mapping, `itertools` for combinations). Use to prevent inefficient manual implementations.
**What to do**: Directly name the recommended library, module, or method in the prompt. Frame it as a requirement for both correctness and efficiency, rather than just a suggestion.
**Example**: "You must use `str.translate()` in combination with `string.punctuation` to remove all punctuation characters from the input string."
**Why it works**: Without explicit instruction, models may choose less efficient, more error-prone manual loops (e.g., checking each character against a list). This ensures the use of optimized, well-tested standard library features.
