Prioritize Clarity and Conciseness in Instructions

**When to apply**: When the core requirement is complex. When the prompt is becoming long with tangential discussions (e.g., debating algorithm efficiency for a simple problem).
**What to do**: State the primary goal first. Use clear, direct language. Avoid nested conditionals in the prompt text. Remove meta-commentary, rhetorical questions, and open-ended suggestions that could distract the model.
**Example**: "Implement a function to calculate the factorial of a non-negative integer n. The function must handle n=0 and n=1 correctly. Use recursion or iteration; either is acceptable. Do not include input/output code; just implement the function."
**Why it works**: Excessive verbosity or ambiguous phrasing can cause the model to focus on minor details or attempt to satisfy conflicting implicit instructions, leading to convoluted or incorrect code. Clear, concise prompts direct the model's attention to the essential task.
