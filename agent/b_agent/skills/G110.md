Anchor the Solution Approach with Clear, Abstract Steps

**When to apply**: For algorithmic or transformation tasks where the solution path is well-defined (e.g., reverse words, implement a specific formula, follow a known procedure). This prevents the model from overcomplicating or misinterpreting the task.
**What to do**: Break down the required algorithm into 2-4 clear, sequential steps using plain English. Describe the operations (split, transform, join, sort, etc.) without revealing the exact Python syntax or function names, thereby anchoring the logic without writing the code for the model.
**Example**: "To solve this, the function should: 1) Split the input string into a list of words based on whitespace. 2) Reverse the order of this list. 3) Join the words back into a single string using exactly one space between each word."
**Why it works**: This provides a strong "reasoning scaffold" for the model. It ensures the model follows the intended algorithm, reducing the chance of creative but incorrect deviations, while still requiring it to generate the actual code itself.
