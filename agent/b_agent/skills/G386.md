Anchor Correctness with Public Test Cases in the Prompt

**When to apply**: When correctness for specific inputs is the highest priority, especially for algorithmic challenges, bug fixes, or replicating known behavior. This ensures the model prioritizes passing given tests over clever but potentially incorrect optimizations or alternative interpretations.

**What to do**: Include a "Test Cases" section in the prompt with 1-3 basic, representative examples. State clearly that the generated code must pass these tests. Format them as clear assertions showing the function call and expected result.

**Example**: "The function must pass the following basic test cases: `is_anagram('listen', 'silent') == True` `is_anagram('hello', 'world') == False` `is_anagram('a', 'a') == True` Prioritize correctness for these cases above all else."

**Why it works**: Models can sometimes produce code that is elegant or efficient but logically flawed on edge cases. By providing concrete public test cases, you give the model a verifiable target. This significantly increases the probability that the generated logic aligns with the intended behavior, as the model implicitly "trains" on these examples.
