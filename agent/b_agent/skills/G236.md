State Core Task and Function Signature in Simple, Direct Language

**When to apply**: At the beginning of any prompt to ensure the model's primary focus is correct. This is the foundational instruction.
**What to do**: In one simple sentence, state what the function should do. In the next sentence, provide the exact function signature. Avoid embedding extra constraints or details here.
**Example**: "Count how many times each character appears in a string. Implement the function `char_frequency(s: str) -> dict[str, int]`."
**Why it works**: Complex or nested phrasing can cause the model to mis-prioritize instructions or miss the primary objective. A clear, upfront statement of the "what" and "interface" anchors the entire generation.
