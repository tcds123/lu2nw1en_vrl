Decompose Core Logic into Clear, Codeless Steps

**When to apply**: For problems where the algorithm is non-trivial but should not be fully spelled out in code. When you need to guide the model's reasoning process without writing the solution for it.
**What to do**: Break down the problem's solution into 2-4 high-level, language-agnostic steps. Describe the operations (filter, transform, compare, accumulate) and their order. Use plain English and avoid Python keywords or library function names.
**Example**: "The solution should follow these steps: 1) Remove all non-alphanumeric characters from the input string. 2) Convert the remaining characters to a single case (e.g., lowercase). 3) Check if the resulting string reads the same forwards and backwards."
**Why it works**: Provides a mental scaffold for the model without over-specifying syntax. It reduces ambiguity in the problem interpretation and steers the model towards the intended algorithm, decreasing the chance of logical errors or misinterpretations.
