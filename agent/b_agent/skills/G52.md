Generate Executable Code Only, Excluding Meta-Instructions

**When to apply**: When the task is to generate a solution for a coding problem (e.g., LeetCode, HackerRank, project requirement). The prompt should be the final instruction to the model, not a draft for a human engineer.
**What to do**: Write the prompt as a direct instruction to the code generation model. The prompt must contain only the problem specification and requirements for the output code. Do not include any notes, comments, or instructions intended for the human who is writing the prompt.
**Example**: "Write a Python function `def is_palindrome(s: str) -> bool:` that returns `True` if the string `s` is a palindrome, ignoring case and non-alphanumeric characters. Only include the function code in your response."
**Why it works**: Code generation models can misinterpret meta-comments like "do not include solution code" as part of the problem specification, potentially leading to no code output, refusal to answer, or the inclusion of the meta-text itself in the generated code comments.
