Ensure Prompt is Syntactically and Logically Clean

**When to apply**: Always, as a final check before using a prompt. Especially critical when modifying or combining prompts, or when they contain placeholder code or pseudocode.
**What to do**: Read the prompt as if you are the model. Check for unmatched quotes, brackets, or broken markdown. Ensure variable names in examples are consistent. Verify that logical flow is sequential and that no instruction contradicts another (e.g., "return a string" vs. "modify the list in-place").
**Example**: "Bad: 'The function should sort the list. For example, process_list([3,1,2]) -> [1,2,3]. It should also remove duplicates.' (Contradiction: sort vs. remove duplicates?). Good: 'The function should sort the list in ascending order and remove any duplicate values.'"
**Why it works**: Models are sensitive to syntax errors and contradictions. A broken code snippet or contradictory instructions can cause the model to generate malformed code, produce errors, or arbitrarily choose one instruction over another, leading to incorrect outputs.
