Define Exact Output Structure and Format

**When to apply**: For any problem requiring formatted output. This includes space/comma-separated values, multi-line outputs, specific rounding of floats, or representations of complex objects.
**What to do**: Specify the exact string that should be printed or returned. Mention delimiters, newlines, and any literal text (like "Case #1:"). For non-string outputs, specify the return type (e.g., "a list of integers").
**Example**: "The function must return a single string. The string should contain the results for each test case, separated by a single space. For example, for results [5, 10, 15], the return string should be `'5 10 15'`. Do not include extra spaces at the start or end."
**Why it works**: Without this, a model might return a Python list `[5, 10, 15]` when the grader expects a string `"5 10 15"`, or print each number on a new line. Explicit formatting instructions ensure the model's output matches the grader's strict string comparison.
