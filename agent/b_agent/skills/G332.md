Mandate Specific Output Format for Clean, Directly Usable Code

**When to apply**: When the generated code must be integrated directly into a project, pasted into a terminal, or used for automated testing. This is critical for tasks like generating a single function, a class definition, or a script where only the final artifact is needed.
**What to do**: Explicitly state the exact format and boundaries of the required output. Instruct the model to output *only* the final code, without explanatory text, within a single, clearly denoted code block. Specify the programming language for the code block.
**Example**: "Output only the final, complete Python function in a single code block. Do not include any explanation, commentary, or text outside the code block."
**Why it works**: Code generation models often preface code with explanations or add summary thoughts afterward, which creates noise and requires manual extraction. This instruction forces a clean, machine-parsable output, saving time and preventing errors from copying incorrect sections.
