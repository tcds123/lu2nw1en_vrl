Ensure Output Format is Complete and Executable

**When to apply**: For any code generation task where the output will be directly executed or evaluated. This is a baseline requirement.
**What to do**: Specify that the output must be a syntactically complete, runnable code unit (e.g., a function, class, or script). Explicitly allow or require necessary imports and supporting structures. Avoid phrases that could be interpreted as "output only a code snippet" missing critical context.
**Example**: "Output a complete, runnable Python function. Include any necessary `import` statements (like `from typing import List`). The function should be defined at the module level and ready to be imported and called."
**Why it works**: Without this, models may generate just the function body without the `def` line, omit crucial imports, or leave placeholders. This instruction ensures the generated code is a self-contained unit that can be copied, pasted, and run without manual fixes.
