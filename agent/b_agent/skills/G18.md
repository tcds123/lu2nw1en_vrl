Ensure Complete, Runnable Code Output

**When to apply**: When the requested solution is a function, class, or script that must be executed independently; when past model responses have been truncated or omitted imports; for tasks requiring a full, self-contained program.
**What to do**: Explicitly instruct the model to provide the entire code block without placeholders or omissions. Mandate that all necessary imports, function definitions, and a final executable piece of code are included. State that the code should be ready to copy, paste, and run.
**Example**: "Provide a complete, runnable Python code block. Include all necessary `import` statements, the full function or class definition, and ensure the code is not truncated. The output should be a single, executable code snippet."
**Why it works**: Code generation models sometimes stop early, output pseudo-code, or omit critical boilerplate (like imports for `math` or `collections`). This explicit requirement forces the model to generate a syntactically complete and directly testable artifact, preventing "solution not found" errors for missing parts.
