Ensure prompt is grammatically coherent and free of formatting noise.

**When to apply**: Always. This is a baseline skill for all prompt construction. Pay special attention when copying text from PDFs, emails, or chat logs that may introduce broken characters, markdown fragments, or incomplete sentences.
**What to do**: After drafting the prompt, read it aloud. Fix any sentence fragments, subject-verb disagreements, or unclear antecedents. Remove stray characters, unmatched brackets, or corrupted symbols. Ensure the prompt flows logically from instruction to constraint to format.
**Example**: "Write a function that validates an email address. The function should return True if the address contains exactly one '@' symbol and at least one '.' after the '@'. Provide the complete Python code." (Instead of: "write function validate email. returns true if has one @ and . after @. code pls.")
**Why it works**: Models are sensitive to prompt clarity. A fragmented, ungrammatical prompt can confuse the model, leading to irrelevant, incomplete, or entirely incorrect outputs. A clean prompt reliably communicates intent.
