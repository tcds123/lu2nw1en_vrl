Instruct to Output Only a Single, Complete Code Block for Execution

**When to apply**: As a final, overriding instruction when stylistic or formatting rules have been specified, to ensure the deliverable is directly executable code.
**What to do**: State explicitly that the model's response must be *only* the requested code, formatted correctly for the target language, with no additional narrative, TODOs, or placeholder comments. Emphasize functional correctness as the primary goal.
**Example**: "Output only the final, complete Python code. Ensure the code is syntactically correct and ready to run. Do not include any explanations, implementation notes, or text outside the code block itself."
**Why it works**: Even with other instructions, models may default to a pedagogical tone. This strong, final instruction acts as a "cleanup" rule, filtering out all non-code artifacts and ensuring the output is a working artifact, not a discussion.
