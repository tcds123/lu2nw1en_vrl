Craft a Fully Coherent and Logically Clear Task Specification

**When to apply**: For every single prompt. This is a baseline skill. The prompt must be a self-contained, understandable description of the problem to be solved.
**What to do**: Write the prompt in clear, grammatical sentences. Structure it logically: state the goal, define inputs and outputs, list constraints, and finally, specify the delivery format. Remove any placeholder text, broken markdown, or incoherent fragments that remained from template editing.
**Example**: "Write a Python function `find_intersection(list1: List[str], list2: List[str]) -> List[str]`. Given two lists of strings, return a new list containing only the strings that appear in both lists, in the order they appear in `list1`. If there is no intersection, return an empty list."
**Why it works**: A garbled or illogical prompt confuses the model, leading to nonsensical code, refusal to answer, or solutions to a misinterpreted problem. Clarity is the foundation of reliable code generation.
