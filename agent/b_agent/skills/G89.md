Define an Expert Persona with Clear Coding Standards

**When to apply**: When generating any non-trivial code module, library function, or production script. Especially crucial for tasks requiring maintainability, collaboration, or integration into a larger codebase.
**What to do**: Explicitly instruct the model to adopt a specific expert persona (e.g., "Expert Software Engineer") and define the coding standards it must follow. Specify requirements for docstrings (format, content), function/variable naming conventions, error handling, and code structure. This sets a high-quality baseline for the output.
**Example**: "You are an Expert Software Engineer. Generate production-ready Python code. Every function must have a complete docstring following the Google style guide, including Args, Returns, and Raises sections. Use descriptive variable names and include appropriate input validation and error handling."
**Why it works**: Without this, models often produce minimal, "works-once" code lacking documentation and robustness. The explicit persona and standards guide the model to generate code that is not just functionally correct but also professional, readable, and maintainable.
