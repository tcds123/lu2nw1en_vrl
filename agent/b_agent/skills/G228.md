Prioritize Function Signature Definition Above All Else

**When to apply**: In all prompts requesting a function implementation. This is a foundational skill for ensuring the generated code has the correct interface, making it a universal first step.

**What to do**: Before describing the problem context, edge cases, or algorithm, state the exact function name, parameter(s) with suggested names, and return type. Treat this as the non-negotiable header for the response.

**Example**: "Define a function with the signature: `def format_currency(amount: float, currency_code: str = 'USD') -> str:`. The rest of the instructions apply to implementing this function."

**Why it works**: Models can get "distracted" by detailed problem narratives and generate code that solves the logic but wraps it in a differently named function or with incorrect parameters. Anchoring the prompt with the signature ensures the model's primary completion task is aligned with the required callable interface.
