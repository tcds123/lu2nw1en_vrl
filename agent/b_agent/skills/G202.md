Enforce Output as a Single, Complete Code Block with No Commentary

**When to apply**: When the output will be piped directly into an interpreter, compiler, or evaluation script, and any surrounding text would cause a syntax error or parsing failure.
**What to do**: Issue a direct, unambiguous command that the entire response must be a single, valid code block (e.g., enclosed in triple backticks for markdown). State that no text, not even a brief introduction, should appear outside this block.
**Example**: "Your entire output must be a single, complete Python code block. Do not write any text before or after the code block. The code block must start with ````python` and end with ````."
**Why it works**: Models are trained to be helpful and explanatory, so they frequently preface code with phrases like "Here's a solution:". This extra text breaks automated systems that expect pure code. A strict, singular block constraint overrides this conversational tendency.
