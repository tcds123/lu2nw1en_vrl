Clearly Define Function Signature, Algorithm, and Performance in Simple Language

**When to apply**: For any non-trivial coding task where correctness depends on a precise interface and efficient algorithm. This synthesizes several skills into a clear, comprehensive instruction set.
**What to do**: Use simple, unambiguous language to state: 1) The exact function signature, 2) The core task in one sentence, 3) The required algorithm or key constraint, and 4) The performance expectation.
**Example**: "Write a function `def merge_intervals(intervals: List[List[int]]) -> List[List[int]]:` that merges all overlapping intervals. Use a sort-based approach: first sort by start time, then iterate and merge. Aim for O(n log n) time complexity."
**Why it works**: This format leaves no room for ambiguity. It gives the model the contract (signature), the goal (task), the method (algorithm), and the quality bar (performance) in a digestible way, covering all bases for generating a correct and efficient solution.
