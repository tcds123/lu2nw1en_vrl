Establish an Expert Coder Persona with Pythonic Conventions

**When to apply**: For Python-specific tasks where idiomatic, clean code is valued over brute-force or verbose solutions.
**What to do**: Frame the instruction from the perspective of an expert (e.g., "As an expert Python developer..."). Emphasize the use of Pythonic constructs (list comprehensions, `enumerate`, `zip`, `collections` module) and clean structure. Avoid unnatural, stiff phrasing.
**Example**: "As an expert Python developer, write a function that groups anagrams from a list of strings. Use Python's standard library for efficiency. The solution should be Pythonic and concise."
**Why it works**: This primes the model to select from a higher-quality set of patterns and idioms inherent to the language, moving beyond basic loop-and-append logic. It discourages C-style or Java-style code translated into Python syntax.
