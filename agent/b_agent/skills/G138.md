Forbid Trivializing Built-Ins to Enforce From-Scratch Implementation

**When to apply**: For educational purposes or when the core of the problem is to understand and implement an algorithm (e.g., sorting, searching, GCD, palindrome checking without `reversed`).
**What to do**: Explicitly name the library functions, methods, or shortcuts that are prohibited. State that the implementation must be "from first principles" or "without using the built-in functionality for the core logic."
**Example**: "Implement a function `my_gcd(a: int, b: int) -> int` that returns the greatest common divisor. You must implement the Euclidean algorithm from scratch. Do not use `math.gcd` or any library function that directly computes the GCD."
**Why it works**: Code generation models are highly skilled at using Python's rich standard library to shortcut algorithmic problems. This instruction forces the model to access its knowledge of the underlying algorithm rather than just API calls, ensuring the generated code demonstrates the intended learning objective.
