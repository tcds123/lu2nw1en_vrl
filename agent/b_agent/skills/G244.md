Provide Complete, Correct Code Stubs and Formatting Templates

**When to apply**: When the task requires a specific function signature, class structure, or output format. When the problem is complex and a starting point is helpful.
**What to do**: Provide a code snippet that is syntactically valid and illustrates the exact expected interface (function name, parameters, return type) and a placeholder for the core logic. The stub should run without syntax errors (even if it doesn't solve the problem).
**Example**: "Complete the following function: ```python\ndef merge_intervals(intervals: list[list[int]]) -> list[list[int]]:\n    \"\"\"Merge all overlapping intervals in a list and return the result.\"\"\"\n    # Your code here\n```"
**Why it works**: Models sometimes invent their own signatures or misformat output (e.g., printing instead of returning). A concrete, correct template sets unambiguous expectations for the code structure, reducing formatting errors and letting the model focus on the algorithm.
