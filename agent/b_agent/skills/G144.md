Define Complete Output Structure: Mandate Runnable Function Definitions

**When to apply**: For any problem requiring a specific callable entity (function, method, class). When the prompt describes a problem but doesn't explicitly state the output form, leaving it ambiguous.
**What to do**: Specify the exact required output structure: a complete, syntactically correct function or class definition. Include the required name, parameters, and return type annotation if applicable. Clarify that a stub or pseudocode is insufficient.
**Example**: "You must output a complete, runnable Python function definition named `calculate_score(data: list) -> int`. The output should be this function, ready to be copied and executed, not a partial implementation or a description."
**Why it works**: Code generation models sometimes output high-level steps, comments about logic, or incomplete code snippets. This instruction forces a concrete, executable artifact, ensuring the solution can be integrated and tested without manual completion.
