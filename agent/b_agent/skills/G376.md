Ensure the Prompt Positively Mandates Code Generation

**When to apply**: In all primary code generation tasks. This is a foundational skill to prevent the model from refusing to answer or providing meta-commentary.
**What to do**: Frame the instruction as a positive, direct command to generate code. Use verbs like "write," "implement," "generate," or "provide." Avoid leading with a list of "do nots" which can prime the model for refusal or over-cautiousness.
**Example**: "Write the Python code to solve this problem." or "Implement the required class and methods as described."
**Why it works**: Models are sensitive to instruction framing. A prompt heavy on prohibitions ("Do not explain," "Do not output anything else") can be interpreted as a restrictive test, sometimes causing the model to hedge or not output code. A clear, positive directive aligns with the model's core training to fulfill requests.
