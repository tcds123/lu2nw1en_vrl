Define Punctuation/Character Handling with Unambiguous, Testable Rules

**When to apply**: For any text processing task involving filtering, removing, or replacing specific character sets (punctuation, digits, whitespace). Prevents ambiguity in whether punctuation attached to words should be removed or split.
**What to do**: Provide a concrete, operational rule that can be directly translated into a condition. Specify the character set (e.g., "all characters in `string.punctuation`") and the action (e.g., "remove", "replace with a space").
**Example**: "Remove all punctuation characters as defined by `string.punctuation`, even if they are adjacent to letters (e.g., 'hello!' becomes 'hello'). Do not insert spaces where punctuation was removed."
**Why it works**: Vague instructions like "clean the text" lead to inconsistent behavior—some models might keep attached punctuation, others might split words. A testable rule ensures deterministic output that matches the evaluator's expected transformation.
