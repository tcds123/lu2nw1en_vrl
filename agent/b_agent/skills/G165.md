Specify the exact function signature and core algorithmic constraint clearly.

**When to apply**: For every function implementation task. The signature is the contract, and the core constraint defines the solution space (e.g., "use recursion", "do not use built-in sort").
**What to do**: State the function name, each parameter with its expected type, and the return type on its own line or in a very clear phrase. Follow this immediately with the key algorithmic constraint in simple, unambiguous language.
**Example**: "Implement a function with the exact signature: `def merge_intervals(intervals: List[List[int]]) -> List[List[int]]`. You must solve this by first sorting the list based on the start time and then merging in a single pass."
**Why it works**: Ambiguity in the signature leads to runtime errors. Vague constraints like "solve efficiently" are interpreted inconsistently. Clear, simple language about the method (sort then merge) directly guides the model's reasoning steps and ensures the solution matches the expected approach.
