Instruct Clear Output Format and Avoid Contradictory Instructions

**When to apply**: For every prompt to ensure the model's response is usable and directly integrable. This prevents the model from adding extra explanations, markdown formatting, or multiple code options when only the final code is needed.

**What to do**: Explicitly state what the model should output (e.g., only the code block, code with docstring) at the end of the prompt. Crucially, review the entire prompt to ensure no earlier instruction contradicts this (e.g., saying "explain your approach" and then "output only code").

**Example**: "Output the complete Python function with its docstring inside a single code block. Do not include any other text, explanation, or commentary in your response."

**Why it works**: Models are often trained to be helpful and explanatory. Without a clear output directive, they frequently precede the code with a textual analysis. Contradictory instructions within the prompt (common in poorly crafted prompts) cause the model to choose one arbitrarily, leading to unpredictable results.
