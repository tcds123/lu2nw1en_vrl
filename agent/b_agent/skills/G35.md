Command Output of Final Code Without Explanations

**When to apply**: This is a stricter, more general version of G348. Apply it universally for all code generation in production or evaluation settings where *only* machine-readable code is acceptable.
**What to do**: Issue a clear, standalone instruction. Make it the final line of the prompt for emphasis. Do not soften it with "please" or conditionals.
**Example**: "Generate the solution. Output only the final, complete code. Do not include any other text."
**Why it works**: It overrides the model's default conversational behavior, minimizing the risk of any explanatory prose, thought process, or commentary that would contaminate the pure code output needed for automated processing.
