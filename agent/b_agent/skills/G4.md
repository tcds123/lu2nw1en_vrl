Instruct to Output Only the Requested Function or Class

**When to apply**: For all code generation tasks where the output will be directly evaluated by an automated judge or integrated into a larger codebase. Always use this unless explicitly asked for explanations.
**What to do**: Use an imperative, unambiguous command at the end of the prompt. State that no additional text, comments (beyond in-line code comments), alternative implementations, or examples should be included in the final output.
**Example**: "Provide the complete Python code for the `Solution` class with the `twoSum` method. Your output must contain only the code, with no surrounding text, markdown formatting, or explanations."
**Why it works**: Language models are trained to be conversational and explanatory. Without this strict instruction, they frequently preface code with "Here's a solution:" or append "This works because...", which breaks automated evaluation scripts expecting pure code.
