Specify Core Logic in Simple, Direct Terms

**When to apply**: For problems involving specific operations like recursion, type handling, or string construction, where the *method* of computation is as important as the outcome.
**What to do**: Use imperative verbs to state the required computational approach. List the data types or structures to be handled and the key operations to perform on them.
**Example**: "Use recursion to traverse the nested structure. Handle both `dict` and `list` types. Join all string keys encountered with a colon `:` separator."
**Why it works**: This cuts through ambiguity. Instead of just describing the goal ("flatten keys"), it tells the model *how* to achieve it, activating the relevant patterns in its training data (e.g., recursive tree traversal patterns) and ensuring type-aware logic is generated.
