Clearly Specify Output Format with Concrete Examples

**When to apply**: When the problem requires a specific data structure (tuple, list, dict, string) for the return value, especially when multiple values are returned or the order matters. Also when the output must match a precise format for automated testing (e.g., LeetCode, HackerRank).

**What to do**: Explicitly state the exact return type and structure. Provide a concrete example input and the corresponding expected output, showing the format. Ensure this example aligns with the most common interpretation of the problem to avoid ambiguity.

**Example**: "The function must return a tuple of two integers: (start_index, end_index). For example, given input `nums = [2,7,11,15]` and `target = 9`, the correct output is `(0, 1)`, not a list `[0, 1]` and not just the values `0, 1`."

**Why it works**: Code generation models often default to returning a list or print statements. Without explicit format specification, they may produce correct logic but in a structure that fails automated tests. A concrete example anchors the model's understanding of the required serialization.
