Use Concise, Imperative Language Focused on the Task

**When to apply**: When drafting any instruction for the model. This skill is foundational and should be applied to the entire prompt to reduce ambiguity and improve the model's focus on executable instructions.

**What to do**: Phrase instructions as direct commands (e.g., "Write a function...", "Use a loop..."). Avoid meta-commentary about the prompt itself (e.g., "I will now ask you to..."), overly abstract descriptions, and jargon not directly related to the coding task. Get straight to the point.

**Example**: Instead of "It would be great if you could perhaps create a function that might process the string in some way," use: "Write a function named `process_string` that takes one string argument and returns a new string with all punctuation removed."

**Why it works**: Verbose, hedging, or abstract language dilutes the signal. Models parse instructions best when they are direct and unambiguous. Unnatural phrasing increases the chance of the model misinterpreting the request or generating equally verbose and indirect code.
