Mandate Edge-Case Handling and Modular, Isolated Output

**When to apply**: For any function or algorithm where inputs can be at extreme ends of the valid range (empty, zero, very small, very large) or have special logical cases. Also essential when the deliverable must be a single, pure function or class without supporting test harnesses.
**What to do**: Explicitly enumerate the critical edge cases to handle. Then, instruct the model to output *only* the requested code construct (function, class) with no additional code, examples, or interactive elements like `if __name__ == "__main__"` blocks unless explicitly requested.
**Example**: "Provide a Python function `def fibonacci(n):` that returns the nth Fibonacci number. You must correctly handle `n = 0` and `n = 1`. The output must be only this function definition, with no extra print statements, input commands, or test code."
**Why it works**: Code generation models frequently omit edge-case logic (returning incorrect values for `n=0`) or generate "demo" code that includes input prompts, which violates the expectation of a pure function. This instruction forces the model to focus on the core, reusable unit of code.
