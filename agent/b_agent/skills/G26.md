Mandate a Self-Contained, Executable Solution with Boilerplate

**When to apply**: For scripts that must run directly (e.g., reading from stdin, processing a file) or when the solution needs to be a complete, runnable program, not just a function snippet.
**What to do**: Instruct the model to include the standard `if __name__ == "__main__":` block for Python. Specify how input should be read (e.g., `input()`, `sys.stdin`). Require that all logic, including parsing, is contained within the generated code.
**Example**: "Provide a complete, runnable Python script. Read an integer `n` from standard input, then read `n` lines of strings. Print the longest string. Your code must include `if __name__ == '__main__':` and handle the input reading."
**Why it works**: Models often generate only the core function, leaving the user to manually write I/O and invocation code. This ensures the generated code is a fully operational program that can be executed and tested immediately.
