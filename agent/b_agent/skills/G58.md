Align Prompt with Exact Problem Statement and Test Cases

**When to apply**: When paraphrasing a problem from a known source (like a coding challenge). Before finalizing the prompt, always cross-reference with the original.
**What to do**: Verify that every requirement, constraint, and example from the original problem is accurately represented in your prompt. Ensure input/output formats, edge cases, and function signatures match exactly. If example test cases are provided, include their input-output pairs in the prompt.
**Example**: "Problem: Given an array of integers `nums` and an integer `target`, return *indices* of the two numbers such that they add up to `target`. Assume exactly one solution, and you may not use the same element twice. Example: `nums = [2,7,11,15], target = 9` → output `[0,1]`. Implement `def twoSum(nums: List[int], target: int) -> List[int]:`."
**Why it works**: Even minor discrepancies (e.g., 0-based vs 1-based indices, returning values vs indices, handling of 'no solution' cases) will cause the generated code to fail the hidden test cases designed for the original, unambiguous problem statement.
