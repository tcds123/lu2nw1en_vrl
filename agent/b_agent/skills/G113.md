Mandate Digit Mapping for Bases >10 Without Providing Implementation

**When to apply**: For any base conversion or numeral system task where the base can exceed 10, requiring symbols beyond '0-9' (typically 'A'-'Z').
**What to do**: Instruct the model that for bases greater than 10, digits from 10 upwards must be represented by uppercase letters (A=10, B=11, ..., Z=35). Do not specify how to implement this mapping (e.g., array, dictionary, calculation), leaving that as a core part of the problem for the model to solve.
**Example**: "For bases greater than 10, use uppercase letters 'A' through 'Z' to represent digit values 10 through 35. The function must implement this mapping correctly."
**Why it works**: This defines a critical output requirement without giving away the algorithm. It forces the model to incorporate the mapping logic, testing its ability to handle this common sub-problem, rather than just outputting a list of numbers.
