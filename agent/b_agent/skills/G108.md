Explicitly Mandate Whitespace Handling with Python String Methods

**When to apply**: For any string processing task where input formatting is non-standard (e.g., normalizing text, parsing words, cleaning data). This is critical for tasks involving user input, file reading, or data transformation.
**What to do**: Directly state that the function must correctly handle edge cases in whitespace, including leading, trailing, and multiple internal spaces. Specify that Python's built-in string methods (like `.strip()`, `.split()`, and `' '.join()`) should be used for this purpose unless the problem explicitly requires a different approach.
**Example**: "The function must robustly handle all whitespace edge cases: strings with leading/trailing spaces, and multiple spaces between words. Use Python's standard string methods (e.g., `str.strip`, `str.split`, and `str.join`) to clean and process the input."
**Why it works**: Models often assume "clean" input and may write logic that fails on real-world data. Explicitly calling out these edge cases and the recommended tools ensures the solution is robust and idiomatic, preventing subtle bugs.
