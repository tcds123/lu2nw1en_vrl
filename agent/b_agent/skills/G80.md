Enforce Exact Output Format with a Defined Delimiter

**When to apply**: When the evaluation system requires an exact string match, such as returning a space-separated list of numbers, a single concatenated string, or a specific sequence of characters. Common in competitive programming or direct stdout evaluation.
**What to do**: Explicitly state the required output format as a single string and specify the delimiter (e.g., space, comma, newline) between elements. Command the model to return nothing else before or after this string.
**Example**: "The function must return a single string where the numbers are separated by a single space, e.g., '1 2 3'. Do not return a list or print anything."
**Why it works**: Models might output a Python list representation `[1, 2, 3]`, a tuple, or include newlines and extra spaces, causing exact-match tests to fail. Specifying the delimiter and string type forces alignment with the evaluator's parsing logic.
