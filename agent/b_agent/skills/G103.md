Mandate Specific Coding Standards and Library Use

**When to apply**: When code quality, maintainability, or portability is important. When the solution must be self-contained for easy evaluation (e.g., in an interview, educational setting).
**What to do**: Require specific elements: a docstring summarizing the function, explicit handling of edge cases within the code, and a restriction to the language's standard library unless otherwise stated. This enforces a professional and robust coding style.
**Example**: "Your implementation must include a docstring, handle edge cases explicitly within the function body, and use only the Python standard library. Do not rely on external packages like `numpy`."
**Why it works**: Without this, models often produce minimal, brittle code lacking documentation. This instruction elevates the output from a mere "answer" to a "solution," making it more readable, testable, and industry-aligned. It also prevents reliance on non-standard modules that may not be available.
