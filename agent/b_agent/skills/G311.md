Explicitly command the model to generate code (e.g., "Write a Python function called X that does Y") before describing constraints.

**When to apply**: Always. This is a universal best practice for initiating a code generation task. It sets the correct mode and output type for the model.
**What to do**: Begin the prompt with a direct imperative verb ("Write", "Create", "Implement", "Generate") followed by the artifact type ("a Python function", "a React component") and its primary purpose.
**Example**: "Write a Python function called `calculate_average` that takes a list of numbers and returns their arithmetic mean."
**Why it works**: It disambiguates the prompt from a question about code ("How do I...?") or a theoretical discussion. It primes the model to start generating executable code blocks immediately, reducing the chance of producing explanatory text only.
