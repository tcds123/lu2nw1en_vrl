Instruct the model to output a complete, syntactically valid code block only.

**When to apply**: For all code generation tasks where the desired output is executable code, not an explanation or a partial snippet. Essential for tasks that will be directly compiled, run, or evaluated.
**What to do**: Use explicit, imperative language. Command the model to output a single, complete code block (e.g., enclosed in triple backticks). State that the response must contain only the requested function(s) and any necessary imports, with no surrounding text, apologies, or commentary.
**Example**: "Output your answer as a single, complete Python code block. The code block must contain only the `calculate_stats` function and any required import statements. Do not include any explanation, comments outside the function, or text before or after the code block."
**Why it works**: Without this instruction, models frequently preface code with explanations like "Here's a solution..." or append notes, which corrupts automated extraction. They may also output incomplete stubs or pseudocode. The strict format ensures clean, ready-to-use code.
