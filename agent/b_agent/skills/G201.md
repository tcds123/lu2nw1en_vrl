Explicitly State the Core Algorithm or Data Structure Approach

**When to apply**: When the solution relies on a specific, non-obvious technique (e.g., anagram detection via sorting, two-pointer traversal, memoization) to be efficient or correct.
**What to do**: Don't just describe the problem; directly instruct the model on the *method* to use. Name the algorithm, key data structure, or transformation that forms the heart of the solution.
**Example**: "Group a list of words into anagrams. Use a dictionary where the key is a sorted tuple of the word's characters (e.g., `sorted(word)`), and the value is a list of words sharing that key."
**Why it works**: Given only a problem description, models may choose a brute-force, incorrect, or inefficient approach. Specifying the core technique steers the model directly to the intended implementation, bypassing flawed reasoning and ensuring optimality.
