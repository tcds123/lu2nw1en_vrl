Ensure Logical Consistency Among Combined Requirements

**When to apply**: When the prompt includes multiple, potentially interdependent requirements (e.g., specific time complexity, banned functions, and a required algorithm). Always review the final prompt for contradictions.
**What to do**: After writing the prompt, check that all requirements can be simultaneously satisfied. For example, requiring "O(1) extra space" and "use recursion" for a large tree is contradictory. Resolve conflicts by prioritizing the core algorithmic mandate or rephrasing.
**Example**: "Implement a prime number generator up to limit `n` that returns a list. You must use the Sieve of Eratosthenes algorithm. The implementation must run in O(n log log n) time. Do not use built-in primality test functions." (All requirements are consistent with the Sieve.)
**Why it works**: Models struggle with contradictory instructions, leading to incoherent code that satisfies one requirement while violating another. A logically consistent prompt yields a coherent and correct implementation.
