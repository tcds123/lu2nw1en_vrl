Keep Prompts Concise and Free of Contradictory Meta-Commentary

**When to apply**: For any prompt that is growing long, contains self-referential instructions (e.g., "be sure to be concise"), or has clauses that may conflict (e.g., "write efficient code" followed by "use the simplest approach possible").
**What to do**: Strip out all commentary about the prompt itself. State the task, interface, and constraints in a clean, sequential list. Use simple, declarative sentences. Remove any phrase that doesn't directly define the output code's requirements.
**Example**: "Write a Python function `find_duplicate(paths)` that parses file directories. Input: `List[str]` where each string is `"root/d1/d2/.../dm f1.txt(f1_content) f2.txt(f2_content) ..."`. Output: `List[List[str]]` grouping full paths of files with identical content."
**Why it works**: Contradictory or meta instructions confuse the model's understanding of priority. Verbosity increases the chance of missing key details. A clean prompt reduces ambiguity and ensures all tokens contribute to specifying the desired output.
