Restate Exact Method Signatures and Attributes Verbatim

**When to apply**: For every problem that defines a function or class interface. This is a foundational step for ensuring compatibility.
**What to do**: Copy the function name, parameter names, parameter types (if specified), return type, and any default values directly from the problem statement into the prompt. Do not paraphrase. Place this signature definition prominently, often at the beginning of the prompt.
**Example**: "You need to implement the following function exactly as specified: `def calculate_tax(income: float, brackets: List[List[float]], deduction: float = 0.0) -> float:`"
**Why it works**: Even minor deviations (like `income: int` vs. `income: float`, or `deduction: float = 0` vs. `deduction: float = 0.0`) can cause type mismatches or default argument issues in strict testing environments. Verbatim repetition minimizes this risk.
