Specify the Algorithm by Name and Define the Precise Function Signature

**When to apply**: For algorithmic problems where a specific technique is required for correctness or efficiency (e.g., "Kadane's algorithm," "Manacher's algorithm," "Dijkstra's algorithm") or when the function's interface is non-negotiable.
**What to do**: Clearly name the required algorithm or approach. Pair this with an exact function signature (name, parameter types, return type) to lock down the interface. This combines high-level strategy with precise contractual requirements.
**Example**: "Implement the solution using the 'expand around center' algorithm for finding palindromic substrings. The function must be defined as `def longest_palindrome(s: str) -> str:`."
**Why it works**: Models might default to a brute-force or different algorithm if not explicitly guided. Naming the algorithm provides direct search/pattern guidance for the model, while the precise signature ensures the generated code drops cleanly into a predefined test suite.
