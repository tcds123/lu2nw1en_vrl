Enforce Concise Implementation with Clear Constraints

**When to apply**: When the solution should be idiomatic and compact (e.g., Pythonic one-liners); to avoid overly verbose, loop-heavy solutions; when the problem is simple but the model might over-complicate it with unnecessary explanations or code.
**What to do**: Directly request the use of specific concise constructs (e.g., list/dict comprehensions, lambda functions, built-in methods) as a constraint. Avoid using complex jargon about the constraint itself; simply state the desired form.
**Example**: "Implement this using a single list comprehension. Do not use a `for` loop or define helper functions."
**Why it works**: Without this directive, models often generate the most generic, instructional-style code (explicit loops, temporary variables), which may be less efficient or idiomatic. The constraint guides the model towards a specific, elegant programming paradigm.
