Structure the Prompt into Clear, Parsable Sections

**When to apply**: For any non-trivial prompt (more than 2 sentences). This is a universal best practice for ensuring all parts of a complex instruction are seen and processed by the model.
**What to do**: Divide your prompt into logical sections with clear headings. Common sections include: `Task`, `Input/Output Format`, `Constraints`, `Examples`, and `Output Requirements`. Keep instructions within each section focused and separate from each other.
**Example**: "**Task**: Find the most frequent word in a string.\n**Input**: A single string `s`.\n**Constraints**: Words are separated by spaces. Comparison should be case-insensitive.\n**Output**: Return the word as a lowercase string."
**Why it works**: This structure mimics the organization of programming problems in training data (e.g., competitive programming sites, documentation). It helps the model's attention mechanism locate relevant information, reducing the chance that a critical detail buried in the middle of a paragraph is missed.
