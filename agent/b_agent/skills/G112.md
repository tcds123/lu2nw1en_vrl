Specify Sign Preservation for Numerical Transformations

**When to apply**: When converting or formatting numbers (especially to strings), and the negative sign is a meaningful part of the value. This applies to base conversion, custom numeral systems, or formatted financial output.
**What to do**: Explicitly state that if the input number is negative, the output string representation must retain the leading negative sign ('-'). The transformation should be applied to the absolute value of the number, with the sign prepended to the final result.
**Example**: "If the input integer is negative, the output string must begin with a minus sign '-'. The conversion logic should be applied to the absolute value of the number, and the sign should be prepended to the final result."
**Why it works**: Models might incorrectly apply a conversion to the negative integer directly (e.g., in base conversion, producing a nonsensical result) or forget to include the sign altogether. This instruction ensures the mathematical integrity of the value is maintained in its string form.
