Mandate a Complete, Runnable Class Definition with a Closing Instruction

**When to apply**: When the requested deliverable is an entire class with multiple methods and internal state (e.g., a `LRUCache`, `Trie`, `MinStack`). A simple function instruction is insufficient.
**What to do**: State the class name and its required methods clearly. End the prompt with a strong, closing directive that calls for the complete, final code in a single, formatted code block.
**Example**: "Design a `MinStack` class that supports push, pop, top, and retrieving the minimum element in constant time. Provide the full, final Python class definition within a single code block."
**Why it works**: Without the closing instruction, models may provide a partial implementation, pseudocode, or an explanation of the approach. The explicit command for "full, final" code in a "single code block" triggers the model's completion mode for delivering production-ready code.
