Suppress All Non-Code Output and Formatting

**When to apply**: When the response will be piped directly into an interpreter, compiler, or automated grading system. When the user's request is strictly for "code only."
**What to do**: Give an explicit, unconditional command to output nothing but the raw source code. Forbid markdown code fences (` ``` `), introductory sentences, and concluding remarks. The entire response should be parsable as source code.
**Example**: "Output only the raw source code. Do not use markdown formatting (like ```python```). Do not include any text before or after the code. The entire response should be the code itself."
**Why it works**: Directly counteracts the model's default chat behavior, which is to frame responses with natural language. This is critical for automation, where any extra text would cause a syntax error or break the evaluation pipeline.
