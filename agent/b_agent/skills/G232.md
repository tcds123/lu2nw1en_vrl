Provide Unambiguous, Contradiction-Free Requirements

**When to apply**: For all complex prompts, especially those combining multiple sub-tasks or constraints. Vital when refining an existing prompt that may have become cluttered.

**What to do**: Review the prompt for internal contradictions (e.g., "don't use loops" followed by "iterate through the list"). Avoid over-specifying *how* to implement unless necessary for constraints; focus on *what* the outcome must be. Ensure all instructions can be followed simultaneously.

**Example**: "**Contradictory**: 'Find the maximum value without using the max function. Iterate with a for loop and use max() to compare.' **Clear**: 'Find the maximum value in the list. You must implement the comparison logic yourself using a loop and a variable; you cannot call the built-in `max()` function.'"

**Why it works**: Contradictory instructions confuse the model, leading to unpredictable outputs where it arbitrarily chooses one instruction to follow and ignores the other. Over-specification (e.g., "use variable `i` in a while loop") can break the model's ability to find a valid solution if the mandated approach is flawed. Clear, coherent requirements allow the model to apply its full problem-solving capability correctly.
