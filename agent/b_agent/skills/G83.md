Restrict Output to Pure Function Definition, Excluding All Extraneous Content

**When to apply**: When the evaluation environment will directly import or exec a specific function from the model's output. Any extra code (tests, prints, global statements) will cause import errors or incorrect execution.
**What to do**: Explicitly command that the output contains *only* the requested function definition (or class definition). Prohibit all other code, including `if __name__ == '__main__':` blocks, example calls, and print statements.
**Example**: "Provide only the `def solve(input_string):` function. Do not include any code outside this function, such as test cases, examples, or a main guard."
**Why it works**: Models frequently add driver code to demonstrate functionality, which corrupts the output when the entire response is treated as the submission. This constraint ensures the output is a clean, importable module.
