Demand Executable Code and Forbid Meta-Descriptions

**When to apply**: When the model has a tendency to output solution descriptions, pseudocode, or comments about its approach instead of actual runnable code. Common in instructional or chain-of-thought tuned models.
**What to do**: Explicitly state that the output must be executable code in the specified language. Use strong prohibitions against natural language explanations, plan outlines, or comments that describe the solution instead of implementing it.
**Example**: "Output executable Python code only. Do not describe your approach, provide pseudocode, or explain the algorithm in comments. The entire response should be valid code that can be run directly."
**Why it works**: Some models default to a "reasoning then code" pattern. This instruction suppresses the reasoning/description phase, forcing a direct jump to the final, evaluable artifact.
