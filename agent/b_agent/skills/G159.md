Mention Key Algorithmic Optimizations by Name

**When to apply**: For problems with well-known optimizations that are not immediately obvious (e.g., primality testing with 6k±1, Kadane's algorithm for max subarray, two-pointer for sorted array pairs). When you want to guide efficiency without writing the code for the model.
**What to do**: Reference the optimization pattern or theorem by its common name or a clear description of its rule, explicitly incorporating it as a requirement.
**Example**: "Implement an efficient primality test. You must use the optimization that all primes greater than 3 are of the form 6k±1, checking divisibility only for numbers of that form up to √n."
**Why it works**: This provides a strong hint that steers the model away from a naive solution without overly constraining the implementation details. It gives the model a "seed" of efficient logic around which to build correct code, dramatically increasing the chance of an optimal solution.
