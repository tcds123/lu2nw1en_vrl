Clearly Command Executable Code as Primary Output

**When to apply**: When the task is to generate a working program, function, or script. When previous prompts have resulted in meta-responses like "Here's how you could do it..." or pseudo-code instead of runnable code.
**What to do**: Use direct, imperative language that leaves no ambiguity about the expected output format. Explicitly state that the output must be a complete, syntactically correct code block that can be executed or integrated. Avoid hedging phrases that suggest optionality.
**Example**: "Your task is to write a Python function. Output *only* the final, executable code within a single code block. Do not include any explanations, commentary, or example usage outside the code block."
**Why it works**: Code generation models can default to descriptive or pedagogical modes. A clear, forceful command overrides this tendency and aligns the model's output with the user's need for immediate, usable code.
