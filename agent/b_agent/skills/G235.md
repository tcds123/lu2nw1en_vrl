Provide a Clear, Concise Persona and Coding Standard

**When to apply**: For all code generation tasks to establish a consistent style and level of expertise, preventing verbose or messy code.
**What to do**: Assign a brief, professional persona (e.g., "Senior Python Developer"). State 2-3 concrete coding standards (e.g., PEP 8, meaningful variable names, use of f-strings) and explicitly prohibit verbosity and contradictory instructions.
**Example**: "You are a Senior Python Developer. Write clean, PEP 8-compliant code. Use descriptive variable names. Avoid unnecessary comments and do not include example usage or test code in the solution."
**Why it works**: Without this, models may generate code with excessive inline comments, print statements for debugging, inconsistent formatting, or exploratory code that doesn't match production-ready expectations.
