Mandate Complete, Executable Class Definitions

**When to apply**: For object-oriented programming problems or when the required output is a full class, not just a function. This prevents generation of partial stubs or method skeletons.
**What to do**: Explicitly state that the output must be a syntactically complete class definition, including the `__init__` method if needed, all required methods fully implemented (not `pass` or `...`), and correct indentation. Specify that it should be ready to run.
**Example**: "Generate a complete, executable Python class `MyHashMap`. Implement the constructor `__init__(self):`, `put(self, key: int, value: int) -> None:`, `get(self, key: int) -> int:`, and `remove(self, key: int) -> None:`. Ensure the code is fully formed and can be executed without additional scaffolding."
**Why it works**: Models sometimes generate high-level pseudocode, leave methods as `# TODO`, or omit the constructor, resulting in non-executable snippets. This instruction pushes the model to produce a final, runnable artifact.
