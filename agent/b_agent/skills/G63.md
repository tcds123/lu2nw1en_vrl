Explicitly Mandate Generation of Executable Solution Code

**When to apply**: For any code-generation task, especially when the user's request is ambiguous (e.g., "How would you solve this?" or "Explain the approach for..."). Always apply unless the task is explicitly about generating pseudocode or an explanation only.

**What to do**: Use a direct, unambiguous instruction that leaves no room for interpretation. Command the model to produce runnable code in a specified language. Never include phrases that suggest withholding the solution.

**Example**: "Your task is to generate a complete, runnable Python solution. Provide the full code implementation. Do not respond with only an explanation, pseudocode, or a plan. The output must be executable Python code."

**Why it works**: Without this instruction, models often default to a "helpful assistant" mode, providing algorithmic explanations, step-by-step plans, or partial code snippets wrapped in commentary, which cannot be executed or evaluated directly.
