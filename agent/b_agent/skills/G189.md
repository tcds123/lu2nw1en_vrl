Mandate Exact Function Signature, Core Algorithm, and Return Format

**When to apply**: When the problem has a single, well-known solution (e.g., string reversal, factorial) or when the output format is critical for integration (e.g., a specific tuple structure). Use when you need to guarantee the generated code matches an exact interface for automated testing.

**What to do**: In the prompt, explicitly write the required function name and parameter list. State the core algorithm or logic approach using precise Python terminology (e.g., "use a list comprehension with `ord()`", "implement using a stack"). Finally, dictate the exact format of the return value, including type and structure.

**Example**: "Write a Python function `reverse_string(s: str) -> str`. The function must reverse the input string `s` using slicing with `[::-1]`. It must return the reversed string. Do not print it."

**Why it works**: Code models often default to common but incorrect patterns (like in-place reversal or returning a list) or over-engineer simple tasks. This precision eliminates ambiguity, directly steering the model to the intended implementation path and output contract, preventing integration errors.
