Ensure Prompt is Syntactically and Semantically Coherent

**When to apply**: When pasting text from other sources, if the prompt contains garbled characters, repeated words, or nonsensical phrases that obscure meaning.
**What to do**: Read the final prompt aloud. Ensure every sentence is complete and conveys a clear, single idea. Remove any artifacts from copying, template placeholders, or mid-sentence edits that create gibberish (e.g., "the function should output the the result result").
**Example**: **Bad Prompt (to avoid):** "Make a fn to reveres a string use slicing and return the the reversed string." **Good Prompt:** "Write a function `reverse_string(s: str) -> str` that returns a new string which is the reverse of the input string `s`. Use Python slicing."
**Why it works**: Models generate code based on patterns learned from clean, coherent text. Gibberish or corrupted instructions introduce noise, causing the model to either fail, generate equally corrupted code, or make its own incorrect assumptions to fill the gaps.
