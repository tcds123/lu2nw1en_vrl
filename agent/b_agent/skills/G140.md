Output Only Final Code: No Explanations, Comments, or Markdown

**When to apply**: In all production or automated evaluation contexts. When the response will be piped directly into a compiler, interpreter, or test suite.
**What to do**: Give a direct, unambiguous command. Use strong verbs like "Output ONLY the code." You can specify the exact expected content: "Your entire response should be the function/class definition."
**Example**: "Your response must contain only the Python code for the `Solution` class. No explanatory text, no summary, no markdown formatting."
**Why it works**: This closes the most common "helpful assistant" failure mode. Models are primed to be conversational. This instruction overrides that default persona, ensuring the output is machine-parsable code, drastically reducing post-processing effort.
