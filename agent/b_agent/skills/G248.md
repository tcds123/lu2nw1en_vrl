Clearly Define Exact Function Signature and Core Logic Directive

**When to apply**: For any function implementation request. When the core logic can be succinctly summarized with a specific technique or property (e.g., "use a set for membership tests").
**What to do**: Present the function signature as the first line of the task. Follow it immediately with a single, imperative sentence stating the key algorithmic action. This creates a clear, two-part contract for the model to fulfill.
**Example**: "Implement `def find_missing_number(nums: list[int]) -> int:`. Use the formula for the sum of the first n natural numbers to find the missing number in the range [0, n]."
**Why it works**: Ambiguous or missing signatures lead to mismatched expectations. A crisp signature paired with a high-level "how" hint (like "use set difference") directly guides the model's planning phase, reducing the chance it wanders into an incorrect or inefficient solution path.
