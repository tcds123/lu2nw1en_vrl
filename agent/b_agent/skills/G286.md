Ensure Grammatical Coherence and Remove Contradictions

**When to apply**: After drafting any prompt, especially one that has been edited multiple times or assembled from fragments. Read it aloud.
**What to do**: Check for subject-verb agreement, run-on sentences, and unclear pronoun references. Eliminate any two instructions that cannot be simultaneously true (e.g., "use recursion" and "avoid function calls").
**Example**: "Poor: 'The function should be fast and don't use loops.' Improved: 'The function must have O(log n) time complexity. Implement it using recursion, without explicit `for` or `while` loops.'"
**Why it works**: Garbled or contradictory text forces the model to guess your intent, leading to unpredictable outputs. Clear, coherent language provides a single, unambiguous interpretation, increasing the reliability of the generated code.
