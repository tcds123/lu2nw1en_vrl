State Sorting Criteria with Unambiguous Precedence and Direction

**When to apply**: For any task requiring multi-criteria sorting or ordering of elements (e.g., frequency analysis, scheduling, ranking).
**What to do**: Define the sort order with absolute clarity. Use phrases like "primary sort", "secondary sort", "descending by", and "ascending by" to eliminate ambiguity. Specify both the key for each criterion and the direction (ascending/descending).
**Example**: "Sort the list primarily by frequency in **descending** order (most frequent first). For items with the same frequency, sort them **ascending** lexicographically (normal dictionary order)."
**Why it works**: Sorting logic is a common source of subtle bugs. Vague instructions like "sort by frequency and then alphabetically" leave the direction ambiguous. Explicit, machine-readable criteria ensure the model implements the exact ordering logic required.
