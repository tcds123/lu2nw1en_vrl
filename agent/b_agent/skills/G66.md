Command a Complete, Runnable Code Solution

**When to apply**: In all code-generation scenarios where the final deliverable is a program, function, or class. This is a foundational skill that should be combined with other constraints (like G61 and G69).

**What to do**: Use imperative language to instruct the model to output the full solution. Specify that the code should be self-contained, include necessary imports, and be ready to run (potentially with example usage in a `if __name__ == "__main__":` block if appropriate).

**Example**: "Provide a complete Python solution. Include all necessary function and class definitions. Your response should contain only the code, or code with a brief docstring. Ensure the code is runnable if copied into a Python interpreter."

**Why it works**: This counteracts the model's tendency to truncate code (e.g., leaving a `# TODO` comment), omitting crucial parts like imports or the main execution block, or embedding the code within a larger explanatory text that cannot be directly executed.
