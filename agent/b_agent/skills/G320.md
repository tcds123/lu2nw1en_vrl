Concisely state core task: signature, behavior, and output

**When to apply**: At the beginning of every prompt to provide an unambiguous summary of the primary goal.
**What to do**: In one or two sentences, combine the function name, its parameters with expected types, a short description of its core transformation/logic, and the format of its return value. This serves as the anchor for all subsequent detailed instructions.
**Example**: "Write a function `flatten_nested_dict(d, parent_key='')` that takes a nested dictionary and returns a flat dictionary with concatenated keys using '.' as a separator."
**Why it works**: Models perform better when the primary objective is immediately clear. Burying the function signature in verbose text increases the risk of misgeneration. This "headline" ensures the model knows the essential output structure from the start.
