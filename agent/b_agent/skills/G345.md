Explicitly Demand Executable Code with a Valid Test Suite

**When to apply**: For all code generation tasks where the output will be directly executed or evaluated. Especially crucial for functions that require specific imports or have complex I/O.
**What to do**: Instruct the model to write complete, runnable code. Mandate the inclusion of a `if __name__ == "__main__":` block or a similar test harness with example calls that demonstrate correctness, including edge cases.
**Example**: "Generate a complete, executable Python script. The solution must include the requested function and a `if __name__ == '__main__':` section containing at least three test cases that validate the function's behavior, including one edge case. The script should run without syntax errors."
**Why it works**: Models sometimes output partial code snippets, pseudocode, or code with missing imports. Explicitly requiring executable code with tests forces the model to produce a final, verifiable artifact and reduces evaluation failures due to trivial omissions.
