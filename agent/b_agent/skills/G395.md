Strictly Enforce Output Format with High-Level Algorithmic Guidance

**When to apply**: When the deliverable must be in a very specific format (e.g., a single function with a docstring, no extra prints) *and* the algorithm is complex enough to require guidance, but not a line-by-line recipe.

**What to do**: Issue a clear, strict command about the output format (e.g., "Only output the final function inside a single code block."). For the algorithm, specify the name and key property, not the implementation steps.

**Example**: "Your entire response must be a single Python code block containing only the `is_prime_sieve` function with a docstring. Implement the Sieve of Eratosthenes algorithm to achieve O(n log log n) time complexity for finding primes up to `n`. Do not include any driver code or examples."

**Why it works**: It separates the *packaging* instruction (strict, non-negotiable) from the *technical* instruction (guideline, conceptual). This prevents the model from omitting the docstring or adding extra text, while still giving it the freedom to correctly implement the well-known algorithm in its own way.
