Structure the Prompt with a Clear, Separated Hierarchy

**When to apply**: For all non-trivial tasks to ensure the model parses the prompt correctly. This is a meta-skill that organizes the application of other skills. It is especially important for complex tasks with multiple requirements, inputs, outputs, and constraints.

**What to do**: Organize the prompt into distinct, labeled sections. A proven structure is: 1) **Persona/Role**, 2) **Core Task** (one-sentence summary), 3) **Function Signature**, 4) **Algorithmic/Functional Requirements** (bulleted list), 5) **Error Handling & Edge Cases**, 6) **Output Format Mandate**.

**Example**: "**Role**: Expert Python Developer. **Task**: Create a function to validate and format user phone numbers. **Signature**: `def format_phone_number(raw_number: str, country_code: str = "US") -> str:` **Requirements**: - Remove all non-digit characters. - Validate length based on `country_code` ('US'=10 digits). - If valid, return in format '(XXX) XXX-XXXX'. **Error Handling**: Raise a `ValueError` with message 'Invalid phone number length' if validation fails. **Output**: Code only, with a docstring."

**Why it works**: A well-structured prompt mirrors how models process information hierarchically. It separates concerns, reduces cognitive load, and makes every requirement easily locatable. This minimizes the chance of the model missing a critical detail buried in a paragraph of text.
