State Core Task and Function Name Clearly at the Prompt's Beginning

**When to apply**: For every code generation request, especially when the problem description is complex or contains background story details.
**What to do**: The very first sentence of the instruction must explicitly name the function (or class) to be generated and its primary purpose. This anchors the model's response. Avoid burying this key information in the middle or end of a paragraph.
**Example**: "Create a Python function named `find_common_elements(list1, list2)` that returns a sorted list of elements common to both input lists."
**Why it works**: Models process the beginning of a prompt with high attention. A clear, upfront declaration sets the correct context and output structure, preventing the model from generating a function with the wrong name, return type, or misunderstanding the primary objective.
