Mandate a Clean, Single-Function Output Without Extraneous Text

**When to apply**: For all code generation tasks where the deliverable is a specific function or class definition, especially when the output will be validated by an automated system.
**What to do**: Explicitly command the model to output **only** the requested code block (e.g., the function definition). Prohibit any explanatory text, comments outside the function, usage examples, or additional code not asked for. The output should be copy-paste executable.
**Example**: "Output **only** the complete Python function definition for `process_data`. Do not include any explanations, example usage, `if __name__ == '__main__'` blocks, or code outside the function body."
**Why it works**: Models frequently add verbose explanations, test code, or extra formatting which can break automated evaluation scripts or clutter the response. This strict instruction filters out all noise, delivering precisely what is needed for integration or testing.
