Structure the Prompt Concisely with Unambiguous Requirements

**When to apply**: For all prompts, but especially when initial attempts yield inconsistent or partially correct outputs, indicating the instructions are confusing or self-contradictory.
**What to do**: Organize the prompt into clear, bullet-pointed or numbered sections (e.g., "Task", "Signature", "Edge Cases", "Output Format"). Use definitive language ("must", "will", "always") and review the prompt to remove any redundant or conflicting statements.
**Example**: "Task: Reverse the words in a string.
- Signature: `def reverse_words(sentence: str) -> str:`
- Behavior: Words are separated by single spaces. Preserve the number of spaces in the input.
- Edge Cases: Return an empty string for `None` or empty string input.
- Output: A single Python code block with the function."
**Why it works**: Ambiguous, verbose, or contradictory prompts lead to models "averaging" instructions or latching onto minor details. A structured, concise prompt reduces cognitive load on the model, aligning its attention with the user's true priorities.
