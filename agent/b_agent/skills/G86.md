Structure the Prompt Concisely to Avoid Conflicting Instructions

**When to apply**: When the prompt contains multiple requirements that could be interpreted as contradictory (e.g., "be efficient" vs. "use simple code"), or when the prompt is overly verbose, increasing the chance of the model missing key details.
**What to do**: Consolidate instructions, remove redundant phrasing, and group related constraints. Present requirements in a logical order: task definition, input/output format, constraints, then prohibitions.
**Example**: Instead of a long paragraph, use: "Task: Reverse the words in a string. Input: A single string `s`. Output: A string with words reversed but original spacing preserved. Constraints: `s` may contain leading/trailing spaces. Do not use `reversed()` or `[::-1]`."
**Why it works**: Overly complex prompts can cause models to focus on minor constraints and miss the core task. A concise, well-structured prompt reduces cognitive load and increases the likelihood of generating correct, on-target code.
