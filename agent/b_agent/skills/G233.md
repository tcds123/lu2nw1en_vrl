Specify Algorithm Name and Key Optimization Steps Clearly

**When to apply**: When the problem requires a specific, well-known algorithm (e.g., sorting, searching, graph traversal, mathematical sieves) or when performance is critical and hinges on a particular optimization.
**What to do**: Explicitly name the algorithm to be used. Then, list 1-3 of its most critical implementation steps or optimizations that are essential for correctness or efficiency. Avoid detailing the entire algorithm; focus on the non-obvious, pivotal parts.
**Example**: "Implement the Sieve of Eratosthenes to find all prime numbers up to `n`. Key steps: 1) Iterate only up to `sqrt(n)`. 2) When marking multiples of a prime `p`, start from `p*p`. Return the list of primes."
**Why it works**: Code models may default to a naive, inefficient implementation (e.g., trial division for primes) even when a standard optimal algorithm exists. Explicitly naming the algorithm and its key optimizations steers the model directly to the correct, efficient solution pattern.
