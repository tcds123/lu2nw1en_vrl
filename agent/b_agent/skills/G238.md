Ensure Prompt is Syntactically Complete and Actionable

**When to apply**: When finalizing a prompt; a self-check to avoid vague, abstract, or incomplete instructions that the model cannot execute.
**What to do**: Read the prompt as if you are the model. Does it end with a clear command (e.g., "Write a function...")? Are all requirements stated as concrete actions? Replace metaphors (e.g., "clean like a surgeon") with concrete attributes (e.g., "efficient and readable").
**Example**: "Write a Python function that validates a Sudoku board. The input is a 9x9 list of lists of integers. The function should return `True` if the board is valid, `False` otherwise. Check rows, columns, and 3x3 sub-grids for duplicates."
**Why it works**: Models process instructions literally. Incomplete sentences, abstract goals, or poetic language introduce noise and uncertainty, leading to incomplete code, misinterpretation of the task, or inclusion of irrelevant meta-commentary.
