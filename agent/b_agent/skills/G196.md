Ensure Prompt Coherence, Grammar, and Freedom from Contradictory Phrasing

**When to apply**: This is a foundational skill for *every* prompt. Always apply it. It is most critical when translating human brainstorming, poorly edited specs, or voice notes into a prompt for generation.

**What to do**: Write the prompt in complete, grammatically correct sentences. Read it aloud to catch awkward phrasing. Verify logical flow: requirement A does not negate requirement B. Replace jargon or ambiguous terms with precise language. Correct spelling and punctuation.

**Example**: **Bad (Garbled):** "function to find max but if list empty handle it good maybe return -1? also do it fast no slow loops."  
**Good (Coherent):** "Write a function `find_max_value(numbers: list) -> int`. If the input list is empty, return `-1`. Otherwise, return the maximum integer value. Optimize for readability."

**Why it works**: Code generation models are highly sensitive to prompt quality. Garbled, ungrammatical, or contradictory prompts are parsed poorly, leading to catastrophic failures where the model generates irrelevant code, gives up, or produces something that addresses only a fragment of the confused request. Clarity is the highest leverage improvement.
