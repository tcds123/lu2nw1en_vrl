Define a Clear Expert Persona and Enforce Code-Only Output

**When to apply**: When interacting with a model that has a tendency to preface its code with explanations, thoughts, or disclaimers. This is vital for generating clean code that can be directly copied and pasted into an editor or testing suite.
**What to do**: Open with a brief, authoritative persona statement (e.g., "You are a senior software engineer."). Follow with the task. Conclude with an unambiguous command that the response must contain *only* code, with no explanatory text, comments about the approach, or markdown outside the code block.
**Example**: "You are a senior software engineer. Write a Python function to reverse a linked list in-place. Your response must contain only the Python code, with no additional text or explanation."
**Why it works**: Many instruction-tuned models are trained to be "helpful" and explain their reasoning. This instruction overrides that tendency, forcing the model into a "code generation only" mode, which streamlines the output for the user and prevents extraneous text from interfering with automated parsing.
