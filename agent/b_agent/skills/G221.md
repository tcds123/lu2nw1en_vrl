Concisely Define Signature, Logic, and Output Format Without Contradiction

**When to apply**: For straightforward code generation tasks where the primary goal is to get correct, runnable code without extra commentary. Essential for API-like interactions.
**What to do**: In 2-3 sentences, combine the key elements: the function signature, the core logic it must implement, and the exact format for the response. Ensure no part contradicts another (e.g., demanding "code only" but also asking for an explanation).
**Example**: "Write a Python function `def is_palindrome(s: str) -> bool:` that returns `True` if the string is the same forwards and backwards, ignoring case and non-alphanumeric characters. Provide only the function code in a code block, with no additional text."
**Why it works**: Contradictory instructions (e.g., "write code" and "explain your reasoning") can lead to mixed outputs. A concise, unified instruction aligns the model's objective, resulting in a clean, directly usable code snippet.
