Use Direct, Unambiguous Language and Structure

**When to apply**: When the prompt uses metaphors, analogies, or conversational fluff. When instructions are nested in complex sentences or passive voice, obscuring the primary action.
**What to do**: Start with a direct imperative for the main task. Use bullet points or clear paragraphs for constraints and examples. Prefer active voice and concrete terms. Remove any language that serves only as motivational or explanatory commentary for a human.
**Example**: Instead of: "Imagine you're cleaning data. You want to be like a gardener pruning a bush, removing the dead branches (invalid entries) to let the healthy ones (good data) shine. Write some code that goes through a list and gets rid of negative numbers." Use: "Write a function `filter_negatives(numbers: list) -> list` that returns a new list containing only the non-negative integers from the input list."
**Why it works**: Figurative language introduces noise. Models parse instructions literally; "pruning a bush" has no semantic mapping to list filtering. Direct, structured prompts align with the model's training on technical documentation and source code, leading to more accurate and reliable generations.
