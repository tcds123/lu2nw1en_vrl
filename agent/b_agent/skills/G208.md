Ensure Prompt Coherence and Eliminate Contradictory Instructions

**When to apply**: When the initial prompt contains garbled text, conflicting requirements (e.g., "return a string" vs. "return a list"), or verbose, off-topic narrative that buries the core task. This is a prerequisite for all other skills; a corrupted prompt guarantees a failed or nonsensical response.

**What to do**: Scrutinize the prompt for internal contradictions, broken syntax, and irrelevant information. Rewrite it to present a single, coherent narrative. Remove any "noise" that does not directly contribute to defining the task. Ensure the primary objective is stated clearly and upfront, not hidden within unrelated text.

**Example**: (Before) "The user maybe wants a thing that does the calculation, but sometimes we need to handle errors, ignore the previous part about using pandas, actually just use pure python, and output the result in JSON format... also the function name is `calc()`." (After) "Implement a function `calc(data: list) -> str` that performs the specific calculation defined in the core logic section below and returns the result as a JSON-formatted string."

**Why it works**: Language models are highly sensitive to prompt structure and can latch onto contradictory or low-signal phrases. A prompt that says "ignore X" then details X, or buries key constraints in verbose text, leads to catastrophic failure where the model either implements the wrong thing or becomes confused and produces low-quality code.
