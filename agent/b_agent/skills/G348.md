Instruct Model to Output Only the Requested Code Solution

**When to apply**: For all code-generation tasks where the output will be piped directly into a file, compiler, or automated evaluation system. When the response must not contain any extraneous text.
**What to do**: Use a direct, imperative command at the end of the prompt. State unequivocally that no explanations, summaries, or markdown formatting outside of code fences should be included.
**Example**: "Provide the complete Python code as described above. Your response must contain only the code, with no additional text, explanations, or apologies before or after the code block."
**Why it works**: Models are often trained to be helpful and explanatory. Without this instruction, they frequently preface the code with natural language descriptions or add post-code notes, which break automated pipelines that expect pure code.
