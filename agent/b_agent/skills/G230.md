Define Exact Output Format with Precise Examples

**When to apply**: For any task where the output's textual format is strictly defined (e.g., generating reports, formatting dates/times, creating structured strings, meeting challenge output specs). Critical when whitespace, rounding, zero-padding, or delimiter placement matters.

**What to do**: Provide a literal example of the required output for a given input. Specify details like number of decimal places, use of spaces vs. tabs, presence of newlines, and exact punctuation. Use "must" and "exactly."

**Example**: "The function must return a string formatted exactly as `'Result: 042.50 units'`. Note the leading zero in `042`, the two decimal places `.50`, and the single space after the colon. For input `42.5`, the output must be `'Result: 042.50 units'`."

**Why it works**: Models will default to a common-sense output (e.g., `42.5` instead of `042.50`), which is often wrong in contexts with strict formatting rules. The concrete example provides an unambiguous template for the model to replicate, preventing formatting errors that cause automated validation to fail.
