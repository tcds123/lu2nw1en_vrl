Prescribe the Core Algorithm or Logic Approach Explicitly

**When to apply**: When the problem's solution hinges on a specific, non-obvious technique (two-pointer, prefix scanning, monotonic stack) or when you want to evaluate the model's ability to implement a given algorithm correctly, rather than discover it.

**What to do**: Name the algorithmic pattern or control flow structure directly. Describe the key operations and termination condition within that paradigm. Use action-oriented language that maps to code constructs.

**Example**: "Write a function `remove_prefix(s: str, prefix: str) -> str`. Use a `while` loop that checks if the string `s` `startswith()` the `prefix`. Inside the loop, use slicing (`s = s[len(prefix):]`) to remove it. Return the final string."

**Why it works**: For problems with multiple potential approaches, a model might choose a cumbersome or incorrect one (e.g., using `replace` for prefix removal, which would also remove internal occurrences). By prescribing the core algorithm, you bypass the solution search and directly test implementation skill, ensuring an efficient and correct method is used.
