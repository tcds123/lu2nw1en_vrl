Structure the Prompt with Clean Formatting and Avoid Noise

**When to apply**: For all prompts. A clean, well-structured prompt is a universal best practice that improves model comprehension and output quality.
**What to do**: Use clear paragraphs, bullet points for constraints or steps, and avoid markdown-heavy formatting that doesn't aid understanding. Write in complete sentences, eliminate redundant phrases, and remove any meta-commentary directed at a human (e.g., "I would like you to...").
**Example**: "Generate a Python class `Rectangle` with an `__init__` method taking `length` and `width`. Include methods for `area()` and `perimeter()`. Ensure the class has a proper docstring. Output only the class code."
**Why it works**: Cluttered prompts with fragmented thoughts, excessive markdown symbols, or conversational fluff can confuse the model's interpretation of the primary instruction. A clean prompt directs the model's attention precisely to the task specifications.
