Specify a Clean, Unambiguous Output Format

**When to apply**: When you need the model's response to be easily parsable (e.g., for automated evaluation) or to avoid a mix of code and lengthy natural language commentary that obscures the solution.

**What to do**: Give a clear, single-format instruction for the output. Common formats include: "Return only the function definition with its docstring," "Output the complete code block with no additional text," or "Provide the solution in a single, formatted code block."

**Example**: "Your entire response should be a single code block containing the Python implementation. Do not include any explanation, analysis, or text outside the code block."

**Why it works**: Models frequently preface code with "Here's a solution:" or follow it with "This code works by...". This "meta-commentary" forces manual extraction of the code and can interfere with automated testing pipelines that expect raw source code.
