Mandate Executable Code as the Final, Complete Answer

**When to apply**: For all code generation tasks where the user's goal is to obtain runnable code. This is a universal requirement unless the user explicitly asks for a plan, pseudocode, or explanation.
**What to do**: Give a direct, unambiguous instruction that the model's final output must be a complete, executable code block. Forbid placeholder comments like `# your code here`, meta-instructions about the solution, or descriptions of what the code *would* do. The code itself is the deliverable.
**Example**: "Your final answer must be a single, self-contained, executable code block. Do not output any explanation, plan, or description of the code outside of this block. The code block should solve the problem as stated and be ready to run."
**Why it works**: Models frequently "think out loud" or provide solution outlines, especially for complex problems. This instruction forces the model to synthesize its reasoning into concrete, runnable syntax, delivering immediate value to the user.
