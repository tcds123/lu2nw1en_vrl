State the Core Task Clearly and Concisely Upfront

**When to apply**: At the very beginning of every prompt; especially for abstract or wordy problem descriptions. This anchors the model's understanding before details are added.
**What to do**: Begin the prompt with a single, clear sentence that defines the primary objective using standard programming terms. Use verbs like "write," "implement," "create," "calculate," or "filter."
**Example**: "Write a function that checks if a string is a palindrome, ignoring case and non-alphanumeric characters."
**Why it works**: Models assign significant weight to the initial context. A vague or meandering opening can misdirect the model's entire approach. A clear, concise first statement establishes the correct context, making all subsequent constraints and details easier to integrate accurately.
