Use Concise, Unambiguous Language; Avoid Decorative Phrasing

**When to apply**: Always. Especially when the task is inherently complex, as verbose prompts increase the risk of the model misinterpreting or overlooking key details.
**What to do**: Use short, direct sentences. Avoid metaphors, motivational language, and redundant explanations. State what the code must *do*, not what it should *be like*. Remove any words that do not contribute to executable instructions.
**Example**: **Instead of**: "Craft an elegant and robust function that, like a skilled artisan, carefully extracts the golden nuggets of numeric data from the rough ore of the input string..." **Use**: "Write a function `extract_numbers(s: str) -> list[int]:` that finds all integer substrings in `s` and returns them as a list of integers."
**Why it works**: Decorative text adds noise and can confuse the model's parsing of intent. Concise, imperative instructions map directly to the model's training on code and documentation, leading to more accurate and functional generations.
