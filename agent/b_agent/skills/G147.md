Ban Built-in Shortcuts to Enforce Manual Algorithm Implementation

**When to apply**: For pedagogical problems or foundational algorithm practice where using a built-in function would trivialize the learning objective (e.g., implementing `atoi` without `int()`, reversing a list without `[::-1]`).
**What to do**: Explicitly list the forbidden built-in functions, modules, or language shortcuts. Mandate that the solution must implement the core logic manually using lower-level operations and control structures.
**Example**: "You must implement the integer-to-string conversion manually. Do NOT use `str()`, `format()`, `f-strings`, or any other built-in conversion function. Implement the digit extraction and string building logic yourself using arithmetic and loops."
**Why it works**: Models often take the easiest path, using high-level abstractions that bypass the intended algorithmic practice. This constraint forces a deeper understanding of the underlying process, which is often the point of the exercise.
