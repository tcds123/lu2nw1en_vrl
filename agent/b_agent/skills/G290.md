Unambiguously Define Function Signature, Core Task, and Output Format

**When to apply**: For virtually every function-generation task. This is the foundational skill for ensuring the generated code interfaces correctly with the rest of a system.
**What to do**: Explicitly state the function name, its parameters with their expected types, and the return type. In a separate sentence, concisely describe the core transformation or calculation the function must perform.
**Example**: "Write a function `def count_vowels(s: str) -> int:` that takes a string `s` and returns the total number of vowel characters (a, e, i, o, u, both cases) present in it."
**Why it works**: Models can hallucinate signatures (wrong parameter order, missing types) or misunderstand the core objective if it's buried in verbose text. A clear, upfront definition acts as a reliable anchor for the entire generation process.
