Define the Contract, Allow Autonomy in Implementation

**When to apply**: When you need to guarantee a specific function interface and handle certain edge cases, but the implementation path has multiple valid variations. This is the standard for most well-specified coding problems.

**What to do**: Precisely define the function signature (name, parameters, return type). Enumerate critical edge cases that must be handled. State any complexity constraints (e.g., O(n) time, O(1) space). Then, allow the model freedom in how it meets these requirements.

**Example**: "Implement `def merge_intervals(intervals: List[List[int]]) -> List[List[int]]:`. The function must merge all overlapping intervals and return a new list. Handle the empty list input. Aim for O(n log n) time complexity. You are free to implement the merging logic as you see fit."

**Why it works**: This provides the necessary guardrails for integration and testing while leveraging the model's strength in generating idiomatic code. It prevents brittle, over-constrained outputs and encourages the model to produce its most natural and often most correct solution.
