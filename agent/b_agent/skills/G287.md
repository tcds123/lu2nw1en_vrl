Provide Clear, Structured Filtering Logic and Output Format

**When to apply**: When the task involves processing a collection to select, transform, or group items based on multiple conditions, and the output has a specific structure (e.g., nested list, dictionary).
**What to do**: Define filtering conditions as a discrete list (e.g., "Include an item if: 1. ... 2. ..."). Then, precisely define the output format (e.g., "Return a dict where keys are X and values are a sorted list of Y.").
**Example**: "Filter a list of `Transaction` objects. Include transactions where: 1. `amount > 1000`, AND 2. `currency` is 'USD' OR 'EUR', AND 3. `status` is 'completed'. Return a list of the included transactions' `id` fields, sorted ascending."
**Why it works**: Without structured logic, models may misapply AND/OR precedence or combine conditions incorrectly. A clear output format prevents the common mistake of returning full objects when only specific fields are needed, ensuring the result integrates seamlessly.
