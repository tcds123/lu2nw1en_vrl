Explicitly List All Functional Requirements Without Omission or Addition

**When to apply**: When translating a narrative problem statement into a technical prompt. This is a foundational step for any code generation task to ensure completeness.
**What to do**: Extract every distinct task the code must perform from the problem statement. Convert them into a bulleted or numbered list in the prompt. Verbally confirm that this list is exhaustive and matches the original problem.
**Example**: "The solution must fulfill all of the following: 1. Read a space-separated string of integers from standard input. 2. Sort the integers in ascending order. 3. Print the sorted list on a single line, separated by spaces. 4. Handle empty input by printing an empty line."
**Why it works**: Problem statements often embed requirements in paragraphs or examples. Models can miss subtle but critical requirements (like edge-case handling) if they are not explicitly enumerated, leading to functionally incomplete solutions.
