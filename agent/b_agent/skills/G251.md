Use Direct, Concrete Language for Algorithmic Instructions

**When to apply**: When describing algorithmic logic, data flow, or problem-solving steps. This is crucial for problems involving iteration, recursion, state management, or mathematical operations.
**What to do**: Replace abstract terms and metaphors with precise, step-by-step commands. Use imperative verbs (e.g., "iterate," "compare," "store," "return") and concrete data structure names (e.g., "list," "dictionary," "queue"). Avoid phrases like "think of it as" or "imagine a scenario."
**Example**: "To solve this, iterate through the input string. For each character, check if it is a digit. If it is, append it to a list. After the loop, convert the list of digit characters into integers and return their sum."
**Why it works**: Models can misinterpret poetic or abstract language, leading to incorrect logic, missing steps, or irrelevant code. Direct instructions map cleanly to actual code constructs, reducing ambiguity.
