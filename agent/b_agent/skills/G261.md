Define Exact Function Signature with Concrete Example

**When to apply**: For any task requiring a function implementation. Essential when parameter types are ambiguous (e.g., "a sequence") or the return format is complex.
**What to do**: Explicitly declare the function name, each parameter with its expected type, and the return type. Immediately follow this with a concrete, realistic input and the corresponding expected output, presented as a comment or `# Example:`.
**Example**: "Implement `def find_common_prefix(strings: list[str]) -> str:`. # Example: find_common_prefix(['flower', 'flow', 'flight']) returns 'fl'."
**Why it works**: Models can misinterpret vague descriptions like "takes a list" (list of what?) or "returns the answer." The concrete example resolves ambiguity in edge case handling (e.g., empty list returns ''), data types, and the exact structure of the return value, serving as a direct test case.
