Explicitly Mandate Generation of Complete, Runnable Code

**When to apply**: At the end of every prompt where the desired output is executable code (a function, class, or script). This is a closing instruction to prevent partial code, explanations, or markdown wrappers.
**What to do**: Use a final, direct instruction that leaves no room for ambiguity about the output format. Specify the exact code unit to generate (e.g., the function body, the entire class). Instruct the model to output *only* that code.
**Example**: "Your final answer must be the complete, runnable Python function `merge_intervals(intervals: List[Tuple[int, int]]) -> List[Tuple[int, int]]` and nothing else. Do not include any explanation, example usage, or markdown formatting like ```python."
**Why it works**: Without this directive, models often default to a conversational style, providing explanations before or after the code, or outputting code wrapped in markdown blocks. This requires manual extraction and can break automated pipelines that expect pure code.
