Instruct Model to Output Only the Requested Code Solution

**When to apply**: For all code generation tasks where the output will be directly executed or tested, and explanatory text would cause a parsing error.
**What to do**: Give a clear, direct command at the end of the prompt that the response must contain only the code (and any explicitly required documentation/comments), with no surrounding explanatory text, usage examples, or markdown formatting outside the code block.
**Example**: "Your response must contain only the Python code for the function and its docstring. Do not include any explanation, example usage, or text outside the code block."
**Why it works**: Without this instruction, models frequently preface their code with natural language explanations, which break automated evaluation pipelines that expect to compile or execute the raw code output directly. This ensures clean, machine-readable output.
