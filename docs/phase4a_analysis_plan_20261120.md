## 0. 研究问题 (用户 2026-11-20 定为首要)

## 3. 首要分析: 训练覆盖度 × 增益分层 (Phase 4-A 的 core)

### 3.1 分层定义 (看到结果前定义, 只看训练侧数据)

| 层 | 定义 | 预计算数量 |
|----|------|-----------|
| L1 stdin 未见失败模式 | test 中 stdin 形式, 且其失败模式粗分类**未在 train fail 27 中出现** | 见 §3.3 |
| L2 stdin 已见失败模式 | test 中 stdin, 失败模式粗分类在 fail 27 中出现过 | 见 §3.3 |
| L3 func / class | test 中裸函数 / class Solution | func 370, class 260 |
| L4 fail-pool 近重复 | 与 fail 27 中任一题近重复 (见 §4) | 21 (全部对 3953) |

- "失败模式粗分类" = 从 fail 27 的**失败原因文本**归纳的标签 (如 截断/样例格式误读/无输出/语法/逻辑错误),
  分类规则在 §3.3 写定后冻结; 不允许看到 pass/fail 后再改标签。
- **注意**: 27 题样本下任何"未出现过的类别"都可能是没抽到而非不存在 → L1 的解释必须带此限定。

### 3.2 判读规则 (预注册)

| 结果 | 判读 |
|------|------|
| L1 的净增益率 CI 下界 > 0 且 ≥ 总增益率的 50% | 支撑"跨题型泛化"主张方向 |
| L1 增益点估计 ≤ 0 或 CI 跨 0, 而 L2/L3 增益显著 | 支撑"已知失败模式定向修复"定位 |
| L1/L2/L3 均 CI 跨 0 | **当前数据无法区分两种故事**; 不得用子组数字讲故事 |
| 任何子组的计划功效 < 0.5 | 只描述, 不下结论 |

- 子组功效 (预计算, 乐观不一致率假设): stdin 需 ≈3033 (有 2134), class 需 ≈1360 (有 260),
  func 需 ≈1670 (有 370) → **所有子组功效不足, 主判读只能靠"分层是否与全体方向一致 + 幅度"**,
  不存在"L1 子组自身显著"的可行路径。

## 4. 重复核验 (已完成, 0 API)

## 9. 用户 2026-11-20 复核意见 (正式结果出来前落盘, 约束报告写法)

1. **分层解释必须收窄**: L1/L2/L3 是按**可观测输入输出形式**划分的题型层; Example 块是题面结构属性,
   不是失败模式标签。报告**不得**把 L1 写成"训练未见过的失败模式", 也不得仅凭 L1 增益证明抽象跨题型泛化。
2. **L3 必须拆分**: 裸函数与 class Solution 的接口约束不同, 正式报告保留 func/class 描述性拆分,
   不许 L3 合并数字掩盖差异。L3 的 C=1.15 **不是** L3 独立因果效应 (其他层负贡献抵消的解释), 不得如此表述。
3. **数据切分限制单列**: 训练集 = 官方 seed42 划分中**按文件顺序取前 80 题**, 非随机抽样 → 题族覆盖不足、
   有效独立样本量偏低; 与测试存在近重复簇。报告须写明: 结论针对 APPS-Plus 异构题库, 不等同对独立新题的泛化。
   **不回头改当前训练集** (破坏可追溯性), 留给 Phase 4-B 分层采样。
4. **正式检查清单** (四项全做): ① 全体配对 (M1/M2 × 2765/2744) 是否成立; ② 收益是否集中 L3 (含 func/class 拆分);
   ③ 截断敏感性是否改变结论; ④ 近重复去重 (2765 vs 2744) 是否改变方向/区间/实际意义。
5. **原则**: 不能用分层结果替代全体结果; 分层是解释工具。最终结论分三层分别回答:
   ① Evolver 是否整体优于两个静态基线; ② 若优于, 收益集中在哪些题型; ③ 现有证据是否足以支持跨题型泛化,
   而非特定接口形式上的定向修复。①成立**不**自动推出③。
