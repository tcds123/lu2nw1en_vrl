## 一、本周关键结论

1. **AIME 线三重饱和，收尾为回归基准** —— 结论饱和 (8+ run 反复确认 in-sample 有效 / held-out 不泛化)、模型饱和 (flash S₀ AIME24 0.854 / AIME25 0.838，信号点仅 9-14 个，检出下限 ~+0.10@k=8,n=30 而候选实际 +0.04~0.08)、瓶颈在 generation 层 (patcher 只修单题不携带跨题通用决策)。AIME 不再作主动实验对象。

2. **强模型让 error-driven 优化在 in-sample 生效，但不跨分布泛化** —— flash evolver in-sample **+0.078 (CI +0.011) 首个显著**，但 AIME25 held-out **+0.017 (CI -0.038) 不显著**。这是本周最核心的结构性结论。

3. **V3.2 LCB 判死前提被推翻** —— flash LCB hard-strat **0.5542 (+36pp vs V3.2 0.193)**，46/83 (55%) 仍失败 → 巨大 headroom，绿灯 option B (self-debug 沙箱)。

4. **截断是主要失败模式，非答错** —— AIME 上 ~75% 失败是 token 截断而非推理错误；cap 4096 对 effective-reasoning 模型严重偏紧 (响应 p90≈22-26k 字符)，截断清零后 d3 有害效应从 -0.233 收窄到 -0.167。

5. **D3 (Astra 修订 skill) 跨学生稳定有害** —— V3.2 16/30、flash 22/30，两套学生均低于 none，-0.167 (p=0.062)。这是唯一跨模型稳定的负效应。
