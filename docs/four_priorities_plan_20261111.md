### 输入/输出成本 × 正确率 (同口径表, 2026-11-11 汇总)

数据源: `P/outputs/flash_aime24_dskills/20261110_144232/results.json` (cap 65536, temp 0, 单次, AIME24 30 题)。
"prompt 剩余 token" = 各臂 `prompt_tokens` 中位数 − none 的 131 (即 skill 块占用的输入);
"输出中位 tok" / "p90 tok" / "中位响应字数" 均在 30 题共同集上计算 (空响应不计入 token 统计);
正确数/正确率按各臂有效样本 n 计 (d1/d2 各有 HTTP 500 除名 1 题)。

| 臂 | skill 大小 | prompt 剩余 token | 输出中位 tok | p90 tok | 中位响应字数 | 无响应 (HTTP 错误) | 正确数/有效 n | 正确率 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| none | 0 | 131 | 1703 | 5088 | 823 | 0 (n=30) | 28/30 | 0.933 |
| s0 | 89 词 | 270 | 1872 | 5567 | 731 | 0 (n=30) | 27/30 | 0.900 |
| d1 | 1366 词 | 2497 | 1488 | 11604 | 559 | **2 (n=28)**: `:63` `:80` | 27/28 | 0.964 |
| d2 | 1312 词 | 1943 | 1406 | 4461 | 551 | **1 (n=29)**: `:63` | 27/29 | 0.931 |
| d3 | 840 词 | 1388 | 776 | 2408 | 295 | 0 (n=30) | 19/30 | 0.633 |

"无响应"含义 (2026-11-11 核实): **不是模型返回空串, 是调用失败**——d1 `:63`/`:80` 为 `HTTP 500 {"code":null}`, d2 `:63` 为 `Remote end closed connection` (均重试 3 次仍失败)。
样本以 `{"error": ...}` 记录, 不计入 n, 也不参与 token 统计, 因此**各臂分母不是同一批题**。

读表要点:
- 输入侧差异真实且可测 (d1 比 none 多 ~2400 prompt token, 19 倍), 输出长度被压缩 30%–65%, 但 none/s0/d1/d2 的正确率与 none 无法区分;
- d1 的 +0.031 (0.964 vs 0.933) 建立在一个**偏差样本**上: 它缺的两题 `:63` `:80` 在 none 上恰好是 1 错 1 对, d1 **不能写成优于 none**;
- d3 是唯一行为与结果同时塌缩的臂 (输出 776 tok ≈ none 的 46%, 正确率 0.633), 且分母完整, 是唯一干净的结论;
- d1 的 p90 11604 tok 远高于其它臂 → 少数题上方法卡让推理显著变长。

**待修口径问题 (未处理)**: ① 3 个 HTTP 500 未补跑 → 全臂 30/30 完整配对缺失;
② 三臂共享的 `:63` 连续失败, 可能是题面/prompt 长度触发的网关问题, 需定位或换端点重试后再统一补跑。
