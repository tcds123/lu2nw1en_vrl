## 实验优先级重排（综合复审 §12.7 + §13.10 + 已有 P2-P6）

原则：复审 §13.10 第 3 步"小型消融优先于大规模重写"为最高指导。**"换表示层/换数据集/换目标"全降级为第 5 步之后。**

1. **干净协议互补矩阵**（§12.1/§13.8 升级）— 中成本，★★★
2. **删段进化**（§12.4）— 低-中，★★★
3. **facet 子集选择**（§12.2）— 低-中，★★★
4. ON 因子消融（§13.10-3，已部分=P3）— 低
5. 带退出条件专家（§12.3）— 中，前置依赖 1-3
6. 同题不同作答形式（§12.5）— 中（题目核验）
7. meta 语义反例诊断（§12.6/§13.9）— 中-高（数学核验）
8. **最后**：四臂（A/B/C/D）或 AIME+per-topic — 高，前置 1-3 信号成立

**关键判断**：1-3 步是"是否值得大规模重写"的判别实验。若全无信号，per-topic/AIME 在 LiveMath 体系下大概率无收益。**AIME+per-topic 从"唯一正方向"降为"第最后步"**——这是对复审 §4/§13.10 的核心让步。

## "超越 skillopt"定位调整（重要）

复审 §13.1 确认 meta 100% 命中是构造关系。**口径纠正(2026-09-28)**: 那个"trivial ensemble（rule meta 1.0 + OFF other 0.415）≈0.67"是**手写规则 + 冻结 baseline 的拼装, 两个分量都不是我们 Facet-Tree 算法的产物**, 是 LiveMath 数据集自身结构(MCQ meta 捷径)的规律, **不能作为"超越 skillopt"的依据**。唯一成立解读: 非算法规则拼装得分高于真优化算法 skillopt(0.5763) → 该基准分数被数据集结构主导、与算法质量无关 → **LiveMath 无法区分算法优劣** → 在 LiveMath 上谈"超越 skillopt"无意义。真正"超越 skillopt"的论证须在**无 MCQ 捷径的数据集（AIME）+ 干净协议**上做, 以我们算法产出的"真数学能力(自由作答)增益"而非"meta 命中率"为主指标。
