# 点估计是采样实现值非真值 — 下结论看 CI 方向非单点 (2026-08-26)

**Why**: paired-CI 复核落盘后, 把配对 point est +0.1056 表述为「消除 s0 噪声后真实增益更接近 +0.106」(已撤回, 见 [[phase-a-axis-combo-result-20260826]] L71). 这是越界: +0.106 是本次 720 calls 的**采样均值实现值**, 不是去噪后真值. CI [+0.0556, +0.1583] 明确告诉你真值可能就在 0.056 附近, +0.106 恰落在区间中段 [(0.0556+0.1583)/2≈0.107] 是 bootstrap 的**常规表现**, 不是「偏上端」信号. 下次 k=10 重采可能 +0.06 也可能 +0.16, 都落在 CI 内. **「看 CI 带非单点」这条纪律我只用在读结果时, 下结论时自己破戒** —— 把保守的「方向显著为正」往激进的「真值≈+0.106」推了一步, 这步没有任何统计依据.

**How to apply**: 下结论涉及 bootstrap CI + point est 时:
- point est 只报「本次采样实现值 = X」, **禁加**「真实增益更接近 X / 真值约 X」——这是把点估计当确认值.
- 唯一可下的结论 = **CI 的方向**: CI_lower > 0 → 方向为正; CI 跨 0 → 方向不显著. **禁报真值量级** (0.05/0.10/0.15 这次分不出来, 都兼容).
- 真值在 CI 区间内任意点都兼容, **不可凭 point est 在区间内的位置** (中段/偏上/偏下) 推断「偏上端/偏下端」——point est 由原始样本均值定, CI 边界由重采样分布定, 两者相对位置是数学常规非信号.
- 报数字时 point est 与 CI **并列报**, 显式标注 point est = "采样实现"性质 (非去噪真值).
- 口径一致: 读结果已守「看 CI 带非单点」, 下结论须**同标准守** —— 结论口径不能比读结果口径松.

**教训**: (1) 纪律只用在读结果上、下结论时破戒 —— 同一条纪律在不同环节口径不一致是隐蔽 bug. 「看 CI 带非单点」要延伸到结论环节: 不仅读 gain 看 CI, 下结论也**只下 CI 能支撑的结论** (方向/显著性), 不下 CI 无法支撑的结论 (真值量级). (2) point est 在 CI 区间内的位置不携带额外信息 —— 它是 bootstrap 的常规几何关系非统计信号, 禁用作「真值偏向」论据. 见 [[phase-a-axis-combo-result-20260826]] L68-71 (本次越界已撤回 + 降格表述).
