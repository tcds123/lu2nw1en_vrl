# A2 Power Analysis — 权威锚定 (2026-08-24)

判据与数字的**唯一权威口径**。design §八改用此表前先读这里。上游 = [[facet-tree-stage0-result-20260821]]
(Stage 0 test 4-seed 数据源), 方法论见 [docs/facet_tree_stage0_gonogo.md](../docs/facet_tree_stage0_gonogo.md)。

## 一句话结论

**大头(判据 gap 0.0511 ≈ 5.9 σ)测得很稳, 小尾巴(+0.34pp 若为真需 ~70 seed)4-seed 测不动。
判据应该盯大头, 别拿小尾巴当 go 门槛。**

## 1. 数据源与锚定 σ

Stage 0 那次 test 106 题 4-seed(eval_k=3)跑出了三组 skill 的 per-seed EM:

| skill | 4-seed per-seed | 4-seed mean |
|-------|-----------------|-------------|
| s0 (baseline) | 0.2862 / 0.2767 / 0.2893 / 0.2987 | 0.2877 |
| evolver (abb71de55a) | 0.5000 / 0.5031 / 0.5157 / 0.4623 | 0.4953 |
| skillopt (上界) | 0.5535 / 0.5723 / 0.5440 / 0.5818 | 0.5629 |

- **σ 锚 = 0.0174** = pooled within-skill 标准差(每组去各自 mean 后合并, df=9=3 skill × (4−1))。
  - 注意: evolver 单组 sd=0.0230(skillopt 0.0170 / s0 0.0094), pooled 被 evolver 高方差
    轻度拉高; 若对 evolver 单独估 σ 会 closer 0.0230 → 效应更保守。0.0174 是含 s0/skillopt
    的低偏差锚。
- **SE(4-seed mean) = σ / √4 = 0.0087**。

## 2. 两个易混点一次说清 (判据线 vs 破天花板线; 0.5464 vs 0.5629)

**易混点 A — 当前 test=106 终评盯的线, 不是 0.4654:**

| 判据 | 值 | 用途 | 状态 |
|------|-----|------|------|
| 破天花板线 (Stage 0) | **0.4654** | 只答"树+交叉 2 代能否破历史 evolver 天花板" | ✅ 已达成(0.4953>0.4654), **已退役** |
| 闭合 SkillOpt 线 (当前终评) | **0.5464** | "显著超"目标值(历史 evolver-probe-split 基线) | ⏳ 当前 test=106 终评要盯的就是它 |

> 口语里常说"判据是 mechanical(不是 0.4654)", 但准确表述是: **0.4654 已退役, 当前判据线 =
> 0.5464**(不是"判据无所谓")。终评命令 `eval_test_multiseed.py ... --seeds 2` 验证的目标 =
> 树+交叉的 evolver best 是否闭合到 0.5464。

**易混点 B — 判据线 0.5464 与 skillopt 实测 0.5629 是**两个不同源**:**

| 数 | 值 | 来源 |
|----|-----|------|
| **判据线** | **0.5464** | design §八 "显著超" 目标值(历史 evolver-probe-split 基线) |
| skillopt 实测 | 0.5629 | Stage 0 这次 4-seed 重测的上界参照(数据, 非判据) |
| evolver 实测 | 0.4953 | Stage 0 这次 4-seed 重测 |

二者不同源 → **判据 gap 必须用 0.5464, 不能用 0.5629。**
(凡是写"gap 0.0676"的地方, 都把它当"落后 skillopt 上界"的旁证读, 不是判据 gap。)

## 3. 真实判据 gap

| 量 | 计算 | 值 |
|----|------|-----|
| 判据 gap = evolver vs 判据线 0.5464 | 0.5464 − 0.4953 | **0.0511** |
| 以 SE(0.0087) 计 | 0.0511 / 0.0087 | **5.88 SE** |
| ~~误写 0.0676~~ | = evolver(0.4953) vs skillopt实测(0.5629) | **非判据 gap, 是"落后上界"旁证** |

**判据栏唯一落盘 = `0.5464 → 0.0511 (5.88 SE)`。** 凡口述"判据 gap 0.0676"均属错位, 应更正为
"evolver 距 skillopt 上界还差 0.0676(旁证)"。

- **5.88 SE ≈ 5.9 σ: 判据达标极其稳**(双侧 t 检验 df=9 下 p ≪ 0.001 量级)。定性"仍超稳"不变,
  只是数字钉对。
- **0.0676 只作旁证**: evolver 距 skillopt 上界还差 0.0676(=7.8 SE), 说明树+交叉**尚未闭合
  val→test gap 到 SkillOpt 水平**, 终局 C 组(开涌现+多代)才是闭合目标。**不进判据, 不作
  go/no-go 门槛。**

## 4. 三分口径判据框架(终局 C 组用它)

1. **涌现相对阈值**(C > E, 涌现轴 > 固定轴): **阈值待 C 组跑完 E 组后定**。以 SE=0.0087 锚:
   2×SE≈0.017 作方向级、3×SE≈0.026 作显著级。**现有数据下 Δ_C−E=0.02 是伪造阈值, 不作默认。**
2. **SkillOpt 绝对 gap**(evolver vs 判据线 0.5464): **=0.0511 = 5.88 SE, 极稳**, 单独构成一个
   判据。
3. **绝对精度**: 0.4953(4-seed)这个绝对值 ±SE 0.0087, 只作**指示性**, 因 per-seed 波动
   (0.4623~0.5157)仍不可忽略。

## 5. 敏感性表(if-效应, 非默认阈值)

σ=0.0174, SE_4seed=0.0087, 标"若真实涌现效应为 Δ 时 4-seed 的可测性":

| 若 Δ_C−E | = 多少 SE | 4-seed 能否测出 |
|----------|-----------|-----------------|
| 0.02 | 2.30 SE | 方向级(勉强), **纯敏感性计算非默认阈值** |
| 0.03 | 3.45 SE | 显著级, 可测 |
| 0.05 | 5.75 SE | 稳健, 可测 |

## 6. 诚实结论 + 小尾巴定性

- **大头**: 判据 gap 0.0511(5.88 SE)超稳, 4-seed 足够定方向 → 判据盯这里。
- **小尾巴**: Stage 0 已达 +0.2075(vs s0), 若还想在 evolver 之上再推 +0.34pp(0.0034),
  需要 ~70 seed(≈(σ×2.8/0.0034)²), **不可行, 只作方向记录不进判据**。
- **落盘口径**: 判据栏 = 0.5464 → 0.0511(5.88 SE); 0.0676/0.5629 只作"落后上界"旁证;
  0.02 一律标 if-效应敏感性。
