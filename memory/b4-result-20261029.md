## 结论 (一句话)

**预登记判据判 (a) 有分离, 但这个"分离"是假象 —— identity 候选自己就 3/5 超出纯采样噪声 p95。cross_q_consistency 在 D2 数据上不能区分信号与噪声, B 改造的 promote gate 按当前公式不应实现。**

按预登记, 结局是 (a); 但预登记同时写了"identity 候选 consistency 若显著偏离 0.5, 说明指标本身有偏" — 这条件被触发, 且证据强于 (a)。**应以指标无效为最终判定**, 而不是 (a)。

## 为什么 (a) 是假象 — 机制

identity 候选 5 次独立重采样, 每次的 cons 落在 0.15–0.85, 但均值归零。这说明:

1. **per-item delta 在 identity 下高度相关** (同一道题在两个不同温度采样下的通过率高度同步: 题本身"几乎必过"或"几乎必挂", k=8 的估计算 law of large numbers 把两臂拉向同一个值)。
2. 一旦某题 base 恰好在 0/1 边界, 两侧 k=8 的弃真/弃假方向一致 → 该题 delta 是 +1 或 −1 的大跳动。
3. **30 题不是 30 个独立观测**。有效样本量远小于 30。
4. Monte Carlo 模型假设题间独立, 因此**低估了**抖动 — 实测 0.346 超过模型 p99=0.286, 这个模型本身就偏乐观。

**更关键的失真**: 用 identity 权重的 cons 作 gate, 会把本来纯噪声的候选 (真效应 0) 推到极端位置 (iter3: 0.846; iter4: 0.154)。这就是 **winner's curse 从"按 mean delta 选"搬到了"按 consistency 选"**, 而不是消除它。

## 连带发现 (2026-10-29, 问题 #15) — 机制表述修正 + 检出下限上调

B4 否证后追查"1a 的 SE=0.0253 / 检出下限 +0.05 是否被本节'题间相关'结论推翻", 复算 identity 候选 5 次重测 mean-delta 跨次展幅 = **0.0587** (naive 0.0265 的 2.22x), 三重自检稳健否定 1a 口径。

**机制表述修正**: 本节原写"per-item delta 高度相关 → 30 题非 30 个独立观测"是对的, 但**根因不是题间相关, 是单题真值跨 run 漂移**。逐题诊断: 同 skill(identity)+温度+k=8, 单题 base 臂通过率跨 5 rep 大幅跳动 (`aime24:65` base=[0.625,0.25,0.125,0.5,0.5], sd=0.205, 远超 k=8 采样理论 ~0.08) → DeepSeek-V3.2 解码非平稳。题间相关只是表象, 真因是模型行为本身 run 间不稳定。

**检出下限上调**: 1a 的 +0.05 是 sd_item/√N (题间独立+题真值固定双重假设) 口径; 真实 SE≈0.04–0.06 → 检出下限 **~+0.10–0.12** (1.96×0.0587≈0.115)。本节末"干净信号 < +0.05 检出下限"应改为"**< +0.10 真实检出下限**" — 结论方向不变 (仍不可区分), 但不确定性区间变宽。详见 `docs/phase2_issues.md` 问题 #15, [[measurement-calibration-1a-20261028]] 口径修正节。

**identity 候选是天然的测量空白对照** (cand==base, 真值精确 0), 应常态化用作噪声标定, 而非只作 winner's curse 的诊断工具。

## 对 B5 (`--cross_q_theta`) 的建议

**不建议实现 B2/B3 的 promote gate**。若一定要有, 必须: (i) 用 sign test 而非常数阈值, 阈值随 n_info 变化; (ii) 在 gate 侧同时要求 `meanΔ_I > 0`, 而不是只用 consistency (否则会选出 cons=0.85 但 meanΔ 只 +0.09 的 identity); (iii) 做 block bootstrap (按题 block) 估 SE, 而非假设 30 个独立样本。

**更根本的建议: 转向 generation 层**。这与 rep5 的结论一致 —— 干净信号本身 < +0.05 检出下限, 说明问题在"候选质量"而非"选谁"。

## 口径与实现说明

1. **pre-registered 判据 vs 实际**: 判据被写成 "存在 theta 使选中候选 held-out delta > 0", 但脚本里没实现这一条 (需与 B2 联动)。若只按极差 + in_band 判, 会误判 (a)。**这是预登记的缺陷, 已在这份结果里显式修正, 而不是改判据去迎合数字**。
2. **两套口径**: 全题口径 (`all`) 的 cons 会随 base 难度漂移 (题越难, zero 题越多, 分母越小, 抖动越大); informative 口径更干净但仍不稳定。本文以 informative 为主。
3. **`*_paired_base` 单行哨兵** (`evolver_facet_paired_base` it1, `evolver_overlay_paired_base` it3) 是 eval_paired 的 stage 探针 (score=0), 已剔除, 不是 evaluator 的观测。
4. **n=30 单 rep** — 无法估跨 rep 稳定度。设计 §2 的 theta≈0.10 (2/30) 是跨 rep 口径, 不适用。
