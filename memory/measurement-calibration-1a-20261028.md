# 1a 先验校准 — AIME24 测量精度真值 (2026-10-28, 纯离线, 零 API)

前置: [[dir2-heldout-gate-result-20261027]]。问题记录见 `docs/phase2_issues.md` 问题 #12。

## 做了什么

不新建 run, 直接用 D2 run (`run_dir2_heldout_gate_rep5_20261027/run_20261027_093001`) 的
`paired_eval_samples.jsonl` (13,442 行) 离线统计。关键结构发现:

- `eval_paired` **每轮都重测 parent** (base 记录与 cand 同量, 每 iter 240/720/240)。所谓 "F2 配对名不副实"
  **不成立**: 日志里 `evolver_*_paired_base` 只有 2 条, 那是 deadline 超时兜底写出的 abandoned 空记录
  (`aime24:62`, iter1/iter3), 不是全部 parent 样本。
- 15 份同协议 S₀@k=8 复测 (facet 5 iter + overlay 5 iter + expand 5 iter) 可直接当独立重复。**这是 σ 的最佳来源**,
  不需要跨 run 汇总。

## 真值

| 量 | 值 |

## 四条结论

1. **F1 的 "σ≈0.044" 高估约 2x**。那是 3 个 run 的 baseline 汇总 (含 run 间漂移), 不是同协议 k=8 复测。
   同协议真值 SE≈0.018–0.025。
2. **检出下限 (95% CI 下界>0, 80% power) 约 +0.05**, 不是 +0.13。F1 的 +0.13 来自 n=30 **单 seed** 口径,
   而现协议是 k=8, 预算高了 8 倍。
3. **去饱和不降 SE, 略升** (n 减而方差未减; 饱和题对分母有利)。若目标是压 SE, 应保留饱和题并扩 n, 而非删题。
   但在 AIME24 只有 30 题 (工程约束 #1 不扩数据集), 没有扩 n 空间。

## ⚠ 口径修正 (2026-10-29, 问题 #15) — 本节 0.0228/0.0253/0.0183 低估约 2x

上述 1–2 条的 SE 数字是**单 run 内**口径 (sd_item/√N, 假设题间独立 + 题真值固定)。B4 否证后追查 identity
候选 (`c11d7dc0c8`, 真效应精确 0) 5 次独立重测 mean-delta 跨次展幅 = **0.0587**, 是本节 naive SE (0.0265,
正好对上 0.0253) 的 **2.22x**; 三重自检 (chi-square 下界 0.0352 仍 > 0.0253; 反向蒙特卡洛 P=0.02%) 稳健否定本口径。

**真实来源不是题间相关, 是单题真值跨 run 漂移**: 同 skill+温度+k=8, 单题 base 臂通过率跨 5 rep 大幅跳动
(`aime24:65` base=[0.625,0.25,0.125,0.5,0.5], sd=0.205, 远超 k=8 采样理论 ~0.08) → DeepSeek-V3.2 解码非平稳。
单 run 内 sd_item/√N 看不见这个误差源, 只有用同真值多 rep 对照才暴露。

**修正后检出下限 ~+0.10–0.12** (1.96×0.0587≈0.115), 不是 +0.05。详见 `docs/phase2_issues.md` 问题 #15。
- 对 D2/rep5 判据: held-out Δ (+0.017/+0.013/+0.025) 不仅 <+0.05, 更 <+0.10, "不可区分"结论**变强**, 方向不变。
- 论文写检出下限不能写 +0.05, 应写 ~+0.10。
- identity 候选 (cand==base) 应常态化作"过程空白"标定每次 run 实际噪声。
4. **饱和题数随 k 变**: 单臂全对 k=8 = 5, 全零 = 3, 任一臂全对或全零各候选 11~18。不存在 "4 vs 11" 矛盾,
   只是口径/k 不同, 不能跨 run 比。

## 对方向的影响

- D2 run 的 3 个 held-out Δ (+0.017 / +0.013 / +0.025) 都 **< 检出下限 +0.05**, 结论 "不可区分" 维持。
- 但 "AIME24 上原理上无法检出任何东西" 这个更强的说法 **不成立**: 候选若真有 ≥+0.05 效应, 现有协议能测出。
- **D2 "0 产出" 的精确表述 (2026-10-29 修正, 原稿 "维持方法无效判断" 过强已撤回)**:
  > 在 AIME24 k=8 paired 协议下, 检出下限 +0.05。D2 产出的候选 held-out Δ 均 <+0.05, 无法与 0 区分。
  > 方法可能无效, 也可能有 +0.02~+0.04 的真效应被噪声淹没——二者在当前协议下不可分。
  依据只能是"3 个 held-out 候选与 0 不可区分" + "1 个 identity 候选真值=0", **不足以外推到全部 25 次尝试**
  (review F1 原话: "0 admit 应解读为测量上限, 不能作为方法确实无效的证据")。
  换方向的理由因此是 **ROI** (继续在 D2 投入回报低), 不是"方法已被证明无效"。
- 真正需要修的测量问题只剩 abandoned 计 0。**偏置方向按臂不同, 不是一概"单向正"**:
  - `eval_on` 路径 (baseline / 非配对 `evolver_*_val`): abandoned → 0 拉低 baseline → **抬高 Δ** (正偏置);
  - `eval_paired` 路径: base 侧 abandoned → 抬高 Δ (正偏置); **cand 侧 abandoned → 压低 Δ (负偏置)**。
  单题量级 ≈1/n≈0.033。D2 里恰好落在真值 0 的题上, 未造成污染, 但属待修 (见 1′)。
