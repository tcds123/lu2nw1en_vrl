# AIME25 held-out 泛化验证 (2026-11-20, 已完成 3-seed)

**验证对象**: run3 best_skill_evolved.md (817 chars, hash e00ed96a47, Quantity Parsing 进化版 "re-express in requested form") vs S₀ (600 chars, hash 735f9e8b71), 在 AIME25 held-out (30 题) 上是否保持 AIME24 的 +0.100 delta / CI+0.011。

**参数**: k=8, seeds=3, cap=8192, retry=0, V3.2, eval_temp=0.3 (与 run3 同口径, paired 同题同 seed)。

## ⭐ 终局 3-seed 结果: delta=+0.019 (CI跨零), 方向微正但不显著

| seed | S₀ | best_skill | diff |
|------|-----|-----------|------|
| 1 | 0.6292 | 0.6292 | +0.000 |

- **主报告 CI = per-problem bootstrap 95% = [-0.017, +0.054]** (B=10000, 多 seed 稳健 [-0.015,+0.055]) — **跨零, 不显著**。bootstrap 以"题"为重采样单位 (n=30), 问答"在随机题目上能否泛化", 是论文泛化叙事的恰当单位。
- 辅助 CI = per-seed paired t-test 95% = [-0.047, +0.086] (df=2, t=4.303, SE=0.0155) — 以"seed"为单位 (n=3), 极保守, 仅 3 样本所以极宽。两者均跨零, 判据位置不变, 但 bootstrap CI 更接近显著边界 (上界 +0.054 vs t-test +0.086), 是更恰当的主报告。
- 衰减: AIME24 +0.100 → AIME25 +0.019 (**81% 衰减**, 非 2-seed 误估的 94%)
- 截断率: S₀ 81/720=11.2%, best_skill 67/720=9.3% — best_skill 仍低 1.9pp (Quantity Parsing 进化不增截断, 3-seed 确认)

## 语义归因: 进化点作用面与题型方向一致 (3-seed 修正后强度下调)

Quantity Parsing 进化点 = "After deriving the answer, re-express it explicitly in the requested form (e.g., m+n=..., probability m/n→m+n)" — 针对**答案形式转换**题。

逐题核对题面"请求形式"与 3-seed 表现:

| 题 | 题面请求形式 | 答案 | 3-seed delta 均值 | 形式转换? |
|----|------------|------|-------------------|----------|
| q24 | "Find remainder when N **divided by 1000**" | 907 | +0.125 (全+) | ✅ 模运算取余 |
| q6 | "概率 m/n, Find **m+n**" | 821 | +0.167 | ✅ 概率→m+n |
| q7 | "sum = m/n, Find **m+n**" | 77 | +0.083 | ✅ m/n→m+n |
| q25 | "Find the **number of ways**" | 113 | +0.125 | ✅ 直接计数→整数 |
| q19 | "Find **arcs in degrees**" (tikz 几何弧) | 336 | -0.042 | ❌ 几何弧度 |
| q28 | "area = **n√3**, Find **n**" | 104 | -0.208 (全-) | ❌ 几何构造 |

**方向一致**: 4 道形式转换题 (q6/7/24/25) 3-seed 均值全正 (+0.083~+0.167), 2 道几何题 (q19/28) 均值全负或近零。进化点在其目标题型上方向性获益、在无关题型上方向性受损 — **归因方向成立**。

**强度下调 (vs 2-seed)**: 2-seed 时 4/4 形式转换题"全 seed 救回"、2/2 几何题"全 seed 搞坏", 像干净因果。seed3 加入后, 只有 q24 (形式转换) 和 q28 (几何) 仍"3 seed 全稳定", q6/7/25 的 seed3 翻转/拉平, q19 也翻转。→ 效应是**题型限定的方向性倾向**, 不是"每题都救回/搞坏"的强因果; 多数题 (28/30) 仍采样噪声主导。

→ **修正结论 (3-seed)**: 不是"4/4 稳定救回"的强归因, 而是"**进化点有题型限定的方向性效应** (4 形式转换题均值正、2 几何题均值负), 但效应强度不足以在 3-seed 下对多数题保持全稳定"。这仍排除了"纯随机过拟合" (方向与进化点作用面一致不是噪声能产生的), 但也排除了"干净题型因果"。

## 对论文的影响 (3-seed 终局)

- AIME24 +0.100 (CI+0.011) → AIME25 +0.019 (bootstrap CI[-0.017,+0.054] 跨零; t-test 辅助 [-0.047,+0.086]), 衰减 81%
- **方向微正但不显著**: delta>0 但 bootstrap CI 跨零, 统计上等同噪声
- **非纯随机过拟合**: 逐题语义归因显示进化点在目标题型 (形式转换) 均值全正、在无关题型 (几何) 均值全负, 方向与进化点作用面一致 (此方向性不是噪声能产生); 但只有 q24/q28 在 3-seed 全稳定, 效应强度不足以对多数题保持稳定
- run3 "首次显著进化" 结论**部分保留**: in-distribution 显著 (+0.100 CI+0.011), OOD 方向对但不显著 (+0.019 CI 跨零)
- 论文应报: "in-distribution +0.100 (CI+0.011); OOD +0.019 (bootstrap CI[-0.017,+0.054], 81%衰减, 方向微正但不显著)。逐题语义归因显示进化点在其目标题型 (形式转换 m/n→m+n, 模运算) 上均值全正、在无关题型 (几何) 上均值全负, 表明衰减源于进化点作用面与 OOD 题型分布的错配 (AIME25 几何题占比 37% vs AIME24 27%), 而非随机过拟合; 但效应强度在 3-seed 下仅对 1/30 题保持全稳定, 多数题仍采样噪声主导。"
- **CI 方法选择**: 主报告用 per-problem bootstrap (题为重采样单位, n=30, 问答"在随机题目上能否泛化", 贴合论文泛化叙事); per-seed t-test (n=3) 仅作辅助, 过于保守。两者均跨零, 判据不变, 但 bootstrap 上界 +0.054 比 t-test +0.086 更接近显著边界, 更能体现"接近但不显著"的真实强度
- **论点定位**: 比"全分布泛化 +0.100"诚实 (OOD 确实衰减), 比"完全过拟合归零"也更有内容 (有可解释的题型限定方向性)。这是一个"机制有效但作用面窄 + OOD 统计功效不足"的诚实中间结论

## 题型分布错配量化 (AIME24 vs AIME25)

| 题型 | AIME24 训练集 (n=30) | AIME25 held-out (n=30) |
|------|---------------------|------------------------|
| 形式转换 (frac→m+n + modulo) | 11 (37%) | 12 (40%) |
| tikz 几何题 | 0 (0%) | 3 (10%) |
| 几何题 (tikz + 文本几何) | 8 (27%) | 11 (37%) |

**错配定位**: AIME25 形式转换题占比**没有下降** (40% vs 37%, 甚至略升), 但**几何题占比显著上升** (37% vs 27%)。进化点在几何题 (无关题型) 上的负效应被放大的分布占比放大, 是 OOD 衰减的主因之一。注: AIME24 含 0 个 tikz 图题, AIME25 含 3 个 — tikz 几何构造题是 AIME24 训练时未见的子类型, best_skill 在其上 q19/q28 均值负。

→ 修正之前表述: 错配**不在"形式转换题变少"**, 在"几何题变多 + 出现训练集未见的 tikz 子类型"。
